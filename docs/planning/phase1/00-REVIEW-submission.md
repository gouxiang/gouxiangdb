## 2. 已锁定的关键架构裁决（评审重点，如有异议请在此处提）

1. **数据路线**：深挖 SQLite（不迁 PG）；量化切库阈值＝单库 >100GB 或单表 >1000 万行 / 改造后 P95 连续 7 天 >800ms / 写 QPS 持续 >100 / 做多租户 SaaS，触一立项 ADR-0008。
2. **导航两层分离（承重墙）**：`nav_nodes` 权威资源节点（唯一父级，决定继承与授权）＋ `menu_items` 菜单引用（可多处/别名/拖拽，不影响权限）。
3. **权限模型：三源并集、纯 allow、不做 deny**。收紧只有两种机制——字段 `fieldMask` 能力裁剪；内容叶子 `inheritAncestors` 中断继承（整篇私密）。
4. **组织模型**：部门物化路径（parentId 真相＋path 派生）、成员可兼多部门、账号 invited/active/disabled 生命周期。
5. **权限落地**：service 层强制，REST/MCP/搜索无旁路；旧 60+ 守卫用适配层零改动；shadow→enforce 灰度（差异清零门）。
6. **向量**：outbox 异步向量化、embedding 三模式（本地 bge-small-zh 默认不出内网 / 云端 OpenAI 兼容可配 / off 降级）、sqlite-vec 派生独立 search.db、FTS5 trigram 中文 + RRF；向量为可 truncate 重建的派生数据，不进业务备份。
7. **MCP（裁决 R-MCP-1 双闸门）**：单 server 双传输（HTTP 挂 Hono `/mcp` + stdio）、PAT 先行、OAuth2.1 预留；`tools/list` 按账号动态过滤、执行期 service 首行强制鉴权，三套机器语言说明书对所有连接者可发现但不含真实数据。
8. **文档/画布机器语言**：锚定 KB Block（align/contentVersion 乐观锁）与 Plait（children 序＝z 序、3×2 网格、显式 id、不碰 WebKit 补偿层）。
9. **备份加密**：age X25519 收件人模式（公钥在备份机、解密 identity 离线），支持无人值守 cron。
10. **部署**：Caddy(TLS)→systemd 单实例 Node→同机 SQLite(WAL)，裸机为主线、Docker Compose 为可选探针。

**部署/发布相关（M0 起持续）：**

- [ ] 附件配额与对象存储策略（U-2 遗留项，本期是否纳入）。
