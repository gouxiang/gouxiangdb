# 构想工作台 0.2.5-beta.1（首个桌面端测试版）

> ⚠️ **预发布（Pre-release）**：这是给内部 / 早期试用者的测试版，不是正式版，**不建议在主力生产数据上使用**。桌面端的「断网可用 + 联网双向同步」在本版**尚未包含**，本版重点是**全新的 macOS 桌面客户端**与**在线帮助百科**。

本版同时提供两个安装包：**macOS 桌面客户端（Apple 芯片）** 与 **飞牛 fnOS 服务器包（x86_64）**。

---

## 一、这一版有什么

### 1. 全新 macOS 桌面客户端（本次主角）
- 一个 `.app` 内含本地服务内核，**双击即用**，不再需要自己装 Node、敲命令。
- **零配置联网**：App 内置本地回路出口代理，浏览器全程同源访问，**连本地节点或远程服务器都不用配置 CORS / 白名单**。
- 支持在启动器里**添加并切换多个节点**（本机库 / 远程服务器）；连远程只选路、不存密码，登录走服务器自己的页面。
- **菜单栏驻留**、关闭窗口默认驻留、彻底退出 / 唤回窗口。
- JWT 密钥存入 **macOS 钥匙串**（service `cc.gouxiang.desktop`），不再明文落盘。
- 适用于 **Apple 芯片（arm64）、macOS 11 及以上**；本版未签名（ad-hoc），**首次打开请右键 App →「打开」→ 在弹窗里再点「打开」**，拖入「应用程序」后使用。

### 2. 在线帮助百科
- 帮助中心改为从 **Gitea Wiki 统一拉取**，文档更新不用再发新版软件。
- 修复了把 Wiki 里的**图片附件（PNG/ZIP 等）误当成帮助页面**，导致列表里出现一堆 png、点进去乱码、页面卡顿的问题——现在只显示真正的帮助页面。

### 3. 服务端为「离线同步」铺好路基（默认关闭，对你毫无影响）
- 服务端已内置一整套双向同步地基（操作日志、版本钟、增量拉取、push 回放、按当前权限裁决、冲突双版本人工选择、结构 / 导航树同步）。
- 由开关 `GX_SYNC_SERVER` 控制，**出厂默认关闭**：不开启时相关接口直接 404、不建表数据、不读写，日常使用与 0.2.4 完全一致。

### 4. 其它
- 设置区可手动声明「服务器对外访问网址」（仅展示 / 复制，不改监听）。
- 启用定稿应用图标套件；登录页与多处导航 / 弹层体验修复。

## 二、安装

### macOS（Apple 芯片 / M 系列）
1. 下载 `构想工作台_0.2.5_aarch64.dmg`，打开后把「构想工作台」拖进「应用程序」。
2. **首次必须右键 → 打开**（未签名的正常提示），确认后再从启动台 / 聚焦正常打开。
3. 本机数据位于 `~/Library/Application Support/cc.gouxiang.desktop/`；删除 App 后该数据目录按 macOS 惯例保留（需要彻底清空可手动删除此目录）。

### 飞牛 fnOS（x86_64）
- 下载 `gouxiangdb-0.2.5-x86.fpk`，在应用中心手动安装 / 在旧版上覆盖安装（数据保留）。
- 要求 Node 运行时 **v22**；登录令牌头使用 `X-GX-Token`（与 0.2.4 相同）。
- 覆盖安装后会执行数据库迁移：本版迁移**只新增、不改旧表、不删列**，存量数据、登录态、附件、品牌图均保留。

## 三、本版【没有】什么（避免误解）
- **桌面端离线编辑 / 断网双向同步本版不含**（那是下一阶段的内测重点 B）。
- 桌面端**在线自动更新暂未接通**（菜单里的「检查更新」当前不可用，新版请手动下载）。
- 无 Apple 开发者签名 / 公证，需右键打开；**仅 Apple 芯片**，Intel 版暂未提供。
- 不含审批 / 工作流（仅预留枚举钩子）。
