# 0.3.1 更新说明

> 这是 0.2.7 之后的第一个正式大版本，重点带来**数据表图表（BI）**、更稳的协同与升级体验，并内置了商业授权、本机离线副本、工作流自动化等新能力。除特别说明的开关外，所有功能升级后即可直接使用，老数据原样保留。

## 新增

- **数据表「图表」视图（第 9 种视图）**：在任意数据表里新建一个「图表」视图，选一个字段作为**分桶维度**（比如「状态」「负责人」「月份」），再选一个**指标字段**和**统计方式**，表格里的记录就会自动聚合成一张图，无需手工做表。
  - 支持**柱图、条形图、折线图、饼图**四种图型，顶部一键切换，换个角度看同一批数据。
  - 统计方式覆盖**求和、平均值、最大值、最小值、计数、空值数、非空数、空值率、填充率**共九种，和表格底部汇总口径一致。
  - 没有填值的记录会单独归到「（空白）」一桶，不会被悄悄丢掉。
  - 图表右上角可**导出 CSV**，拿到 Excel / 表格软件里继续做汇报材料。
  - 记录量特别大、只基于当前已加载部分出图时，页面会明确提示数据范围，不让你误把局部当成全量。
- **本机离线副本（把这台电脑变成可离线使用的副本）**：桌面端可把一台电脑接成服务器的离线副本——没网时也能打开查看和录入，联网后自动与服务器双向同步；同步中心新增「立即同步」，可随时手动跑一轮，并能看到待发送内容、待人工处理的冲突。副本可随时进入、断开、删除，重连只需再粘贴一次连接令牌（令牌只在当次连接使用、不会被保存）。
  - 该能力需要**管理员先在服务器上开启同步服务**后才能接入（默认关闭，见「升级须知」）。
- **商业授权与席位管理（默认只提示、不限制使用）**：管理员后台新增授权状态页，可看到授权是否有效、到期时间、已用席位与机器信息，并内置反馈中心。授权地址与密钥均已零输入化，无需手工填写任何服务器地址或密钥。
  - **默认处于「只提示、不拦人」模式**：即使暂时没有配置授权，也能正常使用全部功能、不影响任何现有账号；只有管理员主动切换到强制模式后，才会按席位数量和到期时间进行限制。到期后数据与账号也都会保留，续费即自动恢复。

## 改进

- **修掉单人编辑时偶发的「假冲突」报错**：同一个人连续编辑文档，偶尔会弹出本不该出现的冲突提示、甚至拦截保存。本版把保存动作改为严格排队、一次只存一笔，并在保存前拦住内嵌表格 / 画布引用丢失，文档和里面嵌的内容不再莫名丢失，引用时也不再多弹一次确认框。
- **文档、画布行尾的「三点菜单」回来了**：二级导航里每条文档 / 画布右侧重新提供重命名、更换图标与颜色、删除等快捷操作。
- **升级后不再「永久转圈」**：客户端每次启动都会先自动把数据库结构升级到位再进入，修复了部分设备覆盖安装后一直停在加载页的问题；同时修复了飞牛覆盖安装残留旧内核导致的数据库报错，以及备份目录缺失时启动失败的问题，整体升级与重启更稳。
- **授权心跳更健壮**：授权状态上报会带上本机局域网与公网出口地址，方便管理员核对设备；网络不通时自动静默降级，不会因为授权服务器暂时连不上就干扰正常使用。
- **飞牛 fnOS 安装包加固**：应用启动、停止、升级、卸载各环节的进程清理与数据库保护进一步加固，覆盖安装和长期运行的稳定性提升。

## 升级须知

- **本版为正式版（非测试版）**，可用于日常生产环境。
- **数据库会自动升级一次**：本版在原有结构上**只新增、不修改、不删除**任何旧表（新增的是为工作流能力预留的几张表）。程序启动时自动完成迁移，老数据、登录状态、附件、品牌设置全部原样保留；稳妥起见，升级前仍建议先做一次备份。
- **两个默认关闭的新能力，需要管理员显式开启**（关着时完全不影响现有功能、也不产生相关数据）：
  - **工作流 / 审批自动化引擎**：内置可视化编排画布、运行记录与审批裁决面板，但默认关闭。导航里能看到入口，未开启时页面会给出启用指引；需要管理员在服务器配置中打开工作流开关后才会生效。这是本版预留、将持续迭代的能力，建议先在非关键场景试用。
  - **离线同步服务端**：要用「本机离线副本」，需管理员先在服务器上开启同步服务；未开启时副本无法接入，其余功能不受影响。
- **商业授权默认不拦人**：正式安装包内置授权能力并默认通电，但出厂为「只提示、不限制」模式，不配授权也能正常用；仅当管理员主动切到强制模式后，新增账号席位上限、到期软挂起等限制才会生效，且被挂起账号的数据与账号本身始终保留、续费自动恢复。
- **macOS 安装**：安装包为 Apple 芯片（arm64）专用、未经苹果公证，**第一次打开请右键点图标 → 选「打开」**；用新 dmg 拖入替换旧版即可，数据落点与钥匙串不变。
- **飞牛 fnOS 安装**：应用中心没有「升级」按钮，需先卸载旧版（**数据与设置会保留**）再安装新包，然后启动；要求 Node 为 v22。本版版本号已更新，可正常覆盖 0.2.7；今后相同版本号的包之间仍不能互相覆盖安装。
- **本版暂不含 / 仍在打磨的部分**：
  - 桌面端在线自动更新的通道已就位，但本版仍以手动下载新包安装为主，菜单里的「检查更新」暂不会自动推送。
  - 图表当前基于已加载到本机的数据在前端聚合，超大数据量下会提示范围；服务端直接聚合的深度优化已列入后续迭代。
  - 工作流与离线同步属全新能力，断网、多人同时改动产生冲突等极端场景仍在持续打磨，欢迎在实际使用中反馈。
  - 暂无 Intel 芯片、Windows、Linux 桌面安装包，Mac 版也暂无苹果开发者签名与公证。
