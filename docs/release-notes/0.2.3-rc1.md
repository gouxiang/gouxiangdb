# 0.2.3-rc1 更新说明（演练版）

> 本版本为「应用内在线更新」机制的端到端演练版本，仅用于隔离环境验证检查、下载、飞牛手动安装全链路。
> 默认渠道不展示预发布版本，需在演练设备显式设置 `GX_UPDATE_ALLOW_PRERELEASE=on` 才能看到本版本。

## 新增

- **应用内在线更新**：工作区所有者可在「工作区设置 → 系统更新」中手动检查新版本、查看更新说明与安装包校验值，并一键下载与当前部署方式匹配的安装包，随后按页面指引在飞牛应用中心手动上传升级。
- 安装包下载经服务器统一代理，支持断点续传；下载链接为 2 分钟内有效的安全票据，更新源令牌不出现在浏览器、链接或日志中。
- 检查更新完全手动触发，后台不轮询、不打扰使用者。

## 改进

- 更新服务不可达、未配置或超时时给出明确中文说明与重试入口。
- 版本无法识别、部署方式未知时在「当前环境」区域标注，便于联系支持时提供信息。

## 升级须知

- 飞牛安装升级包前会自动在线备份当前数据，备份失败会中止升级；数据库与上传文件保存在共享存储中，升级不会删除它们。
- 升级包含数据库迁移，期间服务会短暂重启。
- 安装失败请勿重复强制安装，携带「系统更新」页面的版本与架构信息联系支持。
