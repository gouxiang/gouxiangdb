# 0.3.0 更新说明

这一版是「构想工作台」的**开源归一版**：产品完整源代码以 GNU AGPLv3 协议开放，并确立「开源许可 + 商业许可」双授权模式；同时修好三处此前真机上暴露的缺陷。**本版不改动数据库结构，你的老数据原样保留。**

---

## 新增

### 1. 全面开源，5 人及以下团队永久免费

- 从本版起，构想工作台的**完整源代码**（含桌面客户端、网页端、服务端以及内置的授权校验模块）在 Gitea 公开，采用 GNU Affero 通用公共许可证 v3.0（AGPLv3）。
- **个人、家庭与 5 人及以下的小团队，可以永久免费自由使用**，功能不缩水、人数内不设限。
- 只有两种情况需要另行购买**商业许可**：
  - 团队人数**超过免费档（5 人）**，需要更多席位；
  - 你想在**不公开自己二次开发源代码**的前提下，把基于本软件的产品或服务对外分发 / 对外提供服务（AGPLv3 的网络条款原本要求这种情况下公开你的修改源码，商业许可可豁免这一义务）。
- 授权的**签发服务与签名私钥不包含在开源仓库内**，由作者单独维护；客户端里只有一把用于验签的公钥，无法被伪造利用。完整条款见仓库根目录 `LICENSE` 与 `docs/legal/DUAL-LICENSE.md`。

### 2. 内置授权状态界面

- 管理员在设置里可以直接看到当前实例的**授权状态、可用席位数与已占用人数**，以及免费 / 商业授权的归属情况。
- 界面会在接近或达到免费档上限时给出友好提示，告诉你下一步该怎么扩容，而不是等撞到限制才发现。

## 改进

本版叠接了三处针对真实使用缺陷的修复：

1. **知识库文档快速连写不再丢内容**：以前在文档里快速连续编辑、保存还没完成又接着敲时，后一次保存可能把前一次的改动覆盖掉。现在保存动作会自动排队、一次只落一笔，连续编辑的内容都能完整保存。
2. **远端协作时嵌入的数据表 / 画布不再凭空消失**：修好了一个可能导致文档里嵌入的表格、画布在远端结构回放后丢失的问题（属于数据安全级缺陷）。现在即便远端短暂缺了某块嵌入，本地也会把它稳妥补回；而你主动删除的嵌入不会被错误地「复活」。
3. **左侧导航里丢失的一批菜单入口全部接回**：导航重构后曾有部分操作入口失联，本版统一恢复——数据表行菜单（重命名 / 编辑表单 / 复制 / 清空数据 / 删除）、知识库文档拖拽调整层级、按当前位置新建文档或画布、导入导出按钮、回收站直达，以及文档 / 画布行尾菜单（重命名 / 图标与颜色 / 删除）。

## 升级须知

- **会不会影响我现在正常使用？** 不会。本版授权默认工作在「**只提示、不拦截**」状态：授权界面正常显示、到了免费档上限会提醒，但**不会锁定账号、不会中断任何人正在使用的功能**。5 人及以下团队全程无感。
- **免费额度怎么算？** 按「启用 + 已邀请待激活」的账号数计，**5 席以内免费**。升级前就已经超过 5 人的老团队，系统会一次性记为「老团队」，**已有账号一个都不受影响、不会被停用**，只是此后再新增账号需要商业席位。
- **要联网 / 会上传我的业务数据吗？** 授权状态需要定期与授权中心联网核验（仅核验授权与席位，**不涉及你的表格、文档等业务数据**）。即使暂时连不上授权中心，也只会显示「未能核验」，**不会锁定或中断使用**。
- **数据与迁移**：本版**没有新增数据库迁移**（迁移总数与 0.2.7 相同），不改动任何表结构；授权信息走独立的键值存储，不进业务库。升级前仍建议按惯例做一次备份。
- **飞牛 fnOS 安装**：飞牛应用中心不支持同版本号覆盖安装，先在应用中心「卸载」（**数据会保留**）再安装新的 `.fpk`，然后重新打开即可。
- **macOS 客户端安装**：双击新 `.dmg`，把「构想工作台」重新拖入「应用程序」覆盖旧版。应用仍是 Apple 芯片专用、未做 Apple 公证，**首次启动请在应用程序里右键 → 打开**（直接双击会被系统拦截）。
- **在线自动更新**：本版仍未接通应用内自动更新，请手动到 Gitea Releases 下载新包。
