# 0.2.7-beta 更新说明（测试版）

> 这是在 0.2.7 正式版基础上、提前开放试用的**测试版**，主打「把这台电脑变成可离线使用的副本」。欢迎在日常使用中体验并反馈问题；正式版会在打磨稳定后发布。

## 新增

- **把这台电脑作为副本接入**：Mac 桌面端启动器新增入口——空库时欢迎页的第三张卡片「把这台电脑作为副本接入」，或节点列表底部的「添加本机副本」。只需填写**服务器网址、连接令牌、副本名称（可选）**，点「添加并进入」，这台电脑就会保存一份可离线使用的副本：没网时也能打开查看和记录，联网后自动与服务器双向同步。
- **同步中心新增「立即同步」按钮**：不必等待后台自动同步，想同步时在同步中心点一下即可立刻跑一轮；面板里能直接看到「已同步 / 同步中 / 离线 · 有改动待同步」等状态，以及待发送内容、需要人工处理的冲突和隔离区。
- 副本在节点列表里可随时**进入、断开、删除**；断开后再次进入只需重新粘贴一次连接令牌，服务器地址和副本名称会被记住，无需重填。

## 改进

- 主库、网络服务器、本机副本三者的身份与登录状态彻底分开记录、按当前所在节点精确对应，切换时不再互相串号或要求重复登录。
- **连接令牌只在本次连接时使用、不会被保存**：无论连接成功还是失败，输入框都会立即清空，电脑里不留存该令牌，重新连接时再次输入即可。
- 连接服务器时对网址写法更宽容：网址末尾多一个斜杠等常见写法也能正常连上，不再因此接入失败。

## 升级须知

- **本版为测试版**：建议先在备用电脑或专门的副本机上体验，暂不要用它替换正在使用的主力生产环境；断网、多人同时改动产生冲突等极端情况仍在持续打磨，使用中遇到问题请随时反馈。
- 使用副本前，请确认**要连接的服务器已由管理员开启同步能力**，否则副本无法接入（服务器侧的同步开关默认关闭）。
- 本版**不涉及数据库结构升级**，0.2.6 / 0.2.7 的数据可直接沿用，升级不会删除数据。
- Mac 安装包为 Apple 芯片专用、未经苹果公证，**第一次打开请右键点图标 → 选「打开」**；用新 dmg 拖入替换旧版即可。
- 飞牛 fnOS 上相同版本号的安装包不能直接覆盖安装，需先在应用中心卸载（数据与设置会保留）再安装新包；本测试版**暂不建议**升级 NAS 上正在使用的正式环境。
