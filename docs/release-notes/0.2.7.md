## 〇、给非技术同事的一句话

这一版专门修好了苹果电脑客户端最烦的一个毛病：**以前重启电脑后，之前连过的服务器（远端节点）会凭空消失，得重新手打一遍地址、重新登录**。现在它会牢牢记住，重启后自动回到你上次连的服务器、也不用重新登录。另外这版还修好了「管理员看不到超管建的库」「普通成员被错误地允许授予管理员」等几个权限相关问题。

> 说明：这次只动了 Mac 桌面客户端的「外壳」，**没有改动任何业务数据结构、不涉及数据库迁移**，老数据原样保留。Mac App 依旧是 Apple 芯片专用、未买苹果签名，**第一次要右键 → 打开**。

## 一、本版重点修复

### 1. 头等修复：macOS 重启后远端节点「失忆」（桌面壳固定口）
- **现象**：Mac 客户端在重启电脑（或退出重开 App）后，启动器里之前添加 / 连接过的远端服务器全部丢失，必须重新输入服务器地址；远端登录态、甚至本机登录态也可能要重来。
- **根因（大白话）**：客户端里的网页记忆（localStorage）是按「门牌号」——也就是内部服务的**端口号**——分开存放的。旧版外壳每次启动都随机换一个端口，于是重启后门牌号变了，程序就以为这是一台全新的电脑，旧记忆整屋都找不到了。这不是「没做记忆」，记忆功能一直在，是它脚下的房间号每次都在变。
- **修法**：外壳端口**固定为回环口 `47831`**（只在本机内部通信，不对网暴露）；万一该口被占用，会在 `47832–47836` 里依次找空闲口；极端情况下这些口全被占才退回随机口（保证 App 仍能启动）。门牌号稳定后，浏览器里的记忆自然延续：
  - 远端节点注册表（服务器地址、显示名、上次活动节点）自动恢复；
  - 各远端的登录会话（`gx-node-session:*`，只存登录令牌、**不含密码**）自动恢复，切回免登录；
  - 本机登录态同样不再丢。
- **改动面**：仅 macOS 桌面 Rust 壳（`apps/desktop/src-tauri/src/main.rs` 端口绑定逻辑 + 注释，`shell_server.rs` / `commands.rs` 注释同步）；**前端与服务端零改动、无数据库迁移**。新增 4 个端口选择 headless 测试（主口空闲命中、占用回退、全占随机保底、生产序列以主口打头）。

### 2. 权限相关修复（多提交）
- **管理员看不到超管创建的库（`#1046`/`#1046b`）**：零投影老库的库门加兜底、导航库门改判 `enter`；并在启动时对老库权限投影做**幂等自愈补齐**，重装 / 升级后自动补全，无需人工。
- **提权硬闸（`#1046c`）**：后端硬性规定**非超级管理员不得授予管理员 / 超管角色**；前端对非超管隐藏管理员 / 超管的授予入口，前后端双保险。

### 3. 远端连接场景的菜单与登录态（`22f5db4`，#1056）
- 修好 macOS 壳连接远端服务器时右上角用户菜单点不开的问题；退出登录 / 个人资料按「当前会话所在节点」分槽处理，不再串到本机或别的服务器。

### 4. 详情页编辑体验（`#1047`，多提交）
- 记录详情页编辑态消除「框中框」、输入框不再跳动变大；编辑与只读统一为同一张卡；ghost 融入卡对全字段类型做了适配。

## 四、升级 / 数据须知

- **从 0.2.6 升级**：本版无数据库迁移、无数据结构变更，存量数据 / 登录令牌 / 附件 / 品牌设置原样保留。
- **macOS**：用新 dmg 拖入替换旧 `.app` 即可。升级后第一次启动若旧版当时恰好用的是随机口，其 localStorage 仍挂在旧随机 origin 下、读不回来——这是最后一次；从本版起端口固定 47831，今后所有重启都会延续同一记忆。数据落点不变：`~/Library/Application Support/cc.gouxiang.desktop/`，钥匙串 service `cc.gouxiang.desktop`。
- **飞牛覆盖安装**：appcenter 无 upgrade，先 `uninstall`（保留数据与 env）再 `install-fpk -e <向导文件>`，然后 `start`；要求 Node **v22**。同版本号不能覆盖安装。

## 五、诚实缺口：本版【没有】什么

1. **桌面离线编辑 / 断网双向同步仍不含**（侧车 + outbox + 冲突双栏手选是后续 beta.2 内测形态）。
2. **桌面在线自动更新未正式接通**：本 Release 不带 update-manifest，菜单「检查更新」暂不可用，新版仍需手动下载。
3. **无 Apple 开发者签名 / 公证**：仅 ad-hoc，首次右键打开；仅 arm64，无 Intel / Windows / Linux 桌面包。
4. **帮助中心 Wiki 的版本号文案**在外部 Gitea Wiki 仓库维护，代码仓改不到，需另行更新。
