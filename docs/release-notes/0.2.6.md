## 〇、给非技术同事的一句话

这是构想工作台**第一个带苹果电脑客户端的正式版**：在 0.2.5-beta.1 试用版基础上，把飞牛服务器改成了**独立端口、安装时有向导可填端口**（修掉了此前跨网络访问偶发白屏 / 被网关拦的问题），并修好了**任何人打开公开分享表格都会被错误地踹去登录页**这个最扎眼的毛病。macOS App 依旧是 Apple 芯片专用、未买苹果签名，**第一次要右键 → 打开**。

## 一、相对 0.2.5-beta.1 的变化

### 1. P0 修复：匿名打开公开分享表不再被硬跳登录（`3ea1f65`）
- **现象**：公开分享的表格页（`/s/:token`、`/s/:token/t/:tableId`）任何人匿名打开时，成员列组件无条件请求私有接口 `GET /api/v1/org/members`，匿名态返回 401，被全局拦截器当成「登录失效」硬跳到 `/login`，公开表等于打不开。
- **两层修法**：
  1. `useOrgMembers` 加会话门控——匿名（公开分享）态 `enabled:false`，不发任何私有请求；成员格子 `MemberDisplay` 兜底显示短 id /「—」。
  2. 新增纯函数 `isPublicSharePathname`，拦截器识别公开分享路径：该路径下的私有 401 只复位会话标志，**不登出、不跳转**；品牌名改走公开接口 `/api/auth/branding`。
- 6 文件 +178/-1，新增 13 个测试。

### 2. 飞牛 fnOS 改独立端口交付（`964b6aa`、`d7eb4cc`、`461704e`）
- 弃用旧的 CGI 反代（`/cgi/ThirdParty/...`，会吞 `Authorization` 头、跨源 iframe 偶发白屏），改为**独立端口直接服务**，默认端口 **9527**。
- 安装 / 升级向导可填端口（向导唯一字段 `wizard_port`，范围 1024–65535）；非交互安装必须带环境变量文件 `-e`（`wizard_port=9527`），否则报 `Something wrong with environment variables`。
- 修复桌面连字符图标、升级向导白屏。
- Node 运行时统一 **v22**（better-sqlite3@13 需 NAPI v10，Node 20 会 SIGSEGV）。
- 令牌头历史教训：Web 端用 **`X-GX-Token`**（飞牛网关吞 `Authorization`），后端 `resolveActiveAuth` 两头都收。

### 3. 公开分享能力扩展（`0ff6c20`、`f749a6c`）
- 公开分享支持 **doc / table / base 三类**；base 分享外壳表带 token、可匿名只读打开。
- 修四处分享体验缺陷；CSV 导出附件列改为导文件名。

### 4. 前端视觉体系（v6 底板令牌，多提交）
- 左栏 76px 图标轨、二级面板 236、顶栏 / 工具条 / 弹层 / 知识库 / 通讯录 / 帮助 / 登录等全线迁移到 v6 冷灰底板与发丝线令牌；多处 1:1 精修，配套守护测试。

### 5. 服务端离线同步地基（默认关闭，本桌面版不接线）
- YN0–YN9 在 `apps/api/src/routes/v1/sync/`，由 `GX_SYNC_SERVER` 总门 fail-closed 控制：关闭时整组 404、不建表、不触数据。桌面离线侧车仍是后续内测形态，**本版不含**。

## 三、真机换装实证（飞牛 192.168.31.183，2026-10-23）

- **换装前锁定旧包**：183 原跑的 0.2.6 线上 bundle 是 `index-DTKpWlm-.js`（**marker=0，缺 P0 修复**）。先做双备份（在线一致性 `app.db` + 全量目录旁路含 env / uploads / wal / shm）。
- **换装**：`uninstall`（uninstall_callback **保留** data-share 数据与 env）→ `appcenter-cli install-fpk 新fpk -e wizard_port=9527` → `start`。install_callback 对已存在 env **整块沿用**（`JWT_SECRET` 不重生成），跑 `prisma migrate deploy`（44 枚）+ `nav-reconcile --apply`。
- **换装后硬核验全绿**：
  - 新 pid 起来、`/readyz` 五探针全 true、44 枚迁移；端口 9527。
  - 线上主入口变为 `index-CpXqZ_Ar.js`（**marker=1**，与新 fpk 字节一致）。
  - **登录态不踢**：env 中 `JWT_SECRET` 指纹换装前后均 `1a6691c8a67f`（用自签 owner JWT 实测 `/api/auth/me` 200，匿名 401）。
  - **数据零丢失**：换装前 / 后逐字一致 `users=1 / bases=3 / tables_live=3 / records=8 / attachments=5 / applied=44 / integrity_check=ok`。
- **P0 真机端到端**：owner 建公开 view 分享链接 → **匿名** Chromium 打开 `/s/<token>`：完整渲染 19 列网格 + 1 条记录，成员列显「—」兜底，**未跳 `/login`、零 `/api/v1/org/members` 调用、零 401**，仅 3 个公开接口（branding + 2× public/s）。
- **巡检零报错**：gallery / form / kanban / gantt / tree / 表单问答 / 知识库列表 / 库设置 / 通讯录 / 回收站共 10 页，全部未被踢登录、无空白页、零 5xx、零 pageerror；甘特图为「暂无带日期的任务」优雅空态。
- **收尾**：临时分享链接已吊销（`share_links=0`）、临时表已软删（`temp_table_live=0`），业务计数回到基线。

## 六、诚实缺口：本版【没有】什么

1. **macOS dmg 未在实机做双击 GUI 安装冒烟**（构建链与解包 / 签名 / 版本元数据已核，真机 GUI 待产品负责人在场首验）。
2. **附件文案未做真实点击上传大文件**（常量与守卫测试已对齐，未跑真实上传流）。
3. **帮助中心首页版本号陈旧**：应用内帮助由后端代理**外部 Gitea Wiki**（`apps/api/src/routes/helpProxy.ts`），wiki 源仍写「当前稳定版 v0.2.4 / Mac v0.2.5-beta 内测中」，需在**外部 wiki 仓库**更新，本代码仓改不到。
4. **桌面离线编辑 / 断网双向同步不含**（侧车 + outbox + 冲突双栏手选仍是后续内测形态）。
5. **桌面在线自动更新未正式接通**：本 Release 不带 update-manifest，菜单「检查更新」暂不可用，新版手动下载。
6. **无 Apple 开发者签名 / 公证**：仅 ad-hoc，首次右键打开；仅 arm64，无 Intel / Windows / Linux 桌面包。
