# 0.2.3 更新说明

## 新增

- **应用内在线更新**：工作区所有者可在「工作区设置 → 系统更新」中手动检查新版本、查看更新说明与安装包校验值，并一键下载与当前部署方式匹配的安装包，随后按页面上的图文指引在飞牛应用中心手动上传升级。
- **大包后台预下载（本机秒取）**：发现新版本后，可先点「后台预下载」让服务器在后台把安装包缓存到本机，面板实时显示下载进度；预下载完成后再点下载即为本机秒取，不再受慢网络或网关 30 秒超时影响（解决此前 60MB 安装包在慢公网下经面板下载会失败的问题）。
- 安装包下载经过服务器统一代理，支持断点续传；下载链接为 2 分钟内一次性有效的安全票据，更新源访问令牌不会出现在浏览器、链接或日志中。
- 检查更新不会自动进行，也不会在后台打扰使用者：仅当您手动点击「检查更新」时才会连接更新服务。

## 改进

- 当更新服务暂时不可达、未配置或超时时，面板给出明确的中文说明与重试入口，不再表现为无响应或技术报错。
- 当前版本无法识别、部署方式未知等异常情况会在面板的「当前环境」区域明确标注，便于联系支持时提供信息。
- 修复飞牛 fnOS 环境下应用升级后，内置的「检查更新」访问凭证可能不会自动刷新、导致升级后无法再检测到后续版本的问题；现在每次升级都会自动带上并刷新该凭证。

## 升级须知

- 飞牛 fnOS 在安装升级包前会自动对当前数据做一次在线备份，备份失败会中止升级；数据库与上传文件保存在共享存储中，升级应用不会删除它们。
- 升级包含数据库迁移，期间服务会短暂重启，属正常现象。
- 若安装过程中平台提示失败，请不要重复强制安装，携带「系统更新」页面显示的当前版本与架构信息联系支持。
