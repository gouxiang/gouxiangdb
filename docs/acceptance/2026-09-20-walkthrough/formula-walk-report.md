| `CONCAT(...)` | 空串 |
| `MOD(x,0)` / `/0` / `%0` | **空白（null）**，从不写入 NaN / Infinity 脏值 |

软删记录自动被排除出计算（`deletedAt: null` 过滤生效，见 5.2）。
