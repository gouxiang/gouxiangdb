## 二、保存机制与持久化

- **机制：自动保存为主，手动保存为辅**。
  - 每次编辑后约 1200 ms 防抖自动 PUT（与 `useDocPersistence.ts:155` 一致）。
  - 顶栏「保存」按钮可立即触发保存（`persist.saveNow()`）。
  - 保存状态提示存在：「有未保存更改」→「已保存到云端」。
- **持久化：已验证真实生效**。
  - 新建矩形/圆形/箭头/文本后未手动保存，等待数秒后刷新，图形仍在（canvas-21-恢复画布内容.png）。
  - 关闭浏览器、重新登录后再次打开同一画布，内容一致。
- **未验证项**：409 冲突二选一、本地草稿恢复、10 MB 上限边界。

- **撤销/重做**：在画布上绘制三角形后按 `Ctrl+Z` / `Ctrl+Shift+Z`，截图前后无变化，**未能验证 Drawnix 自带 undo/redo 是否真正生效**。

## 四、因找不到入口/无法建立选择态而漏验的功能

1. **选中、框选、多选、移动、缩放、旋转、删除、复制粘贴**：agent-browser 的鼠标 down/up 事件无法让 Drawnix 进入选择态，因此相关功能均未真实点验。
2. **样式条（颜色/描边/字体/z 序/节点注释/关联角标）**：因无法选中元素，未能逐条验证。
3. **连线形态/端点箭头**：未选中连线，未验证。
4. **图片插入**：工具条图片按钮无可见 `<input type=file>`，`agent-browser upload` 因元素无 box model 失败，未能在 UI 上完成插入。
5. **思维导图/自由画笔/橡皮**：操作后未在画布上看到明显新元素，未确认是否真正生成。
6. **画布 ↔ 数据表记录关联**：已确认界面上**无此能力**（符合已知限制 V28）。
7. **全屏按钮**：顶栏只有「保存/分享/版本历史」，无全屏按钮（符合已知限制）。

## 六、结论

- 画布**新建、重命名、自动/手动保存、持久化、分享、版本历史、公开只读预览**链路通顺，数据确实落盘。
- **核心绘图工具**（矩形、圆形、三角形、箭头、文字）可在真实界面生成元素。
- 受自动化工具与 Drawnix 选择态交互的兼容性限制，**选中、移动、删除、复制粘贴、z 序、样式条、撤销重做等大量操作未能完成真实点验**；这些问题需要人工使用真实浏览器补测。
- 未发现 P0 级数据损坏或安全越权问题。

### 6.2 选择态主线攻克结果

前次失败根因是**坐标定位错误**：画布经历过缩放/平移后，元素实际屏幕坐标发生了变化，仍用初始坐标点击导致命中空白区域。改用「框选拖拽」并先查询元素 BBox 后，选择态可稳定触发。

已验证操作（均在复核画布 `画布复核2` 上完成，截图前缀 `canvas2-`）：

| 操作 | 结果 | 关键截图 |
| --- | --- | --- |
| 框选选中单个/多个元素 | 成功；出现蓝色选中框与控制点 | canvas2-04 / canvas2-05 |
| 拖动选中元素 | 成功；元素位置改变 | canvas2-06 |
| 修改描边颜色 | 成功；描边实时变红 | canvas2-21 |

| 两元素连线 | 成功；箭头连接矩形与椭圆 | canvas2-40 |

**未完全验证**：
- **删除**：按 Delete 键在部分场景下未删除选中元素（可能与焦点在 text/样式条有关），未形成稳定复现结论。
