## 四、针对「视图设置生效性」的 4 个用例（戴总点名缺口）

1. **用户态排序隔离**：A 视图按数量降序（30/20/10 → 甲丙乙），B 视图仍是默认创建序（甲乙丙），回到 A 排序仍保留。
2. **管理员字段隐藏**：A 视图设置 → 数据展示移除「数量」→ 表头由五列变四列；B 视图五列仍在；再「添加字段」恢复数量。
3. **管理员强制筛选**：三条记录状态分别设为未开始/进行中/已完成，A 强制只看未开始 → 只剩 1 条；B 不受影响仍 3 条；清空后回 3 条。
4. **记录抽屉布局编辑**：抽屉 → 编辑字段布局 → 数量宽度改为 100 → 保存布局。服务端读回该字段宽度确为 100，且表头五列仍在（只改布局、未物理删字段）。

## 五、补测过程中主动发现并修复的真实产品缺陷

1. **CSV 导出把单选/多选内部选项 id（`opt_xxx`）写进文件**，未转成选项名。
   - 修复：`apps/api/src/domain/csv.ts` 的 `recordToRow` 增加 id→选项名映射（提交 `dde594b`）。
2. **网格单元格点击穿透到行 onClick 打开抽屉，双击无法编辑单元格**。
   - 修复：`GridRow.tsx` 数据列 `<td>` 打 `data-cell-content` 标记并由行首守卫拦截（提交 `dde594b`）。
3. **搜索防抖 hook 在 React 18 StrictMode 开发态挂载约 300ms 后，零点击自动提交一次搜索并写回整份视图配置**。
   - 根因：`useDebouncedCommit` 的 `first.current` 首次跳过标志在 StrictMode"挂载双调用 effect"时失效。
   - 修复：`apps/web/src/components/interaction.tsx` 改为比较"已提交权威值 committedRef"，任意次 effect 重跑均幂等（提交 `7ce456b`）。
4. **附件上传回调把同一服务端文件重复追加**，产生重复列表项与重复 React key。
   - 修复：`AttachmentUploader.tsx` 按 id 去重后再追加（提交 `7ce456b`）。
