## 4. 交互链路实测记录

每条均为真实点击（Playwright click / eval dispatch），非仅渲染观察。

### 4.1 登录 → 进库 → 打开表 ✅
- 登录页表单（浏览器密码管理器预填凭据）→ 点击「登录」→ 200 → 跳转 `/base/.../view/...` → `localStorage["gx-auth"].state.token` 写入。
- 证据：20-login-success.png；API 日志 `POST /api/auth/login 200`。
- ⚠️ 观察项：浏览器自动填充值不触发 React onChange，首次点击登录无反应、需真实输入；属已知前端行为，非本次重构引入。

### 4.2 新建记录 ✅
- 「新建记录」按钮点击一次 → 记录数稳定 +1（10→10+1，含 6 秒稳定窗复核）。**防重复提交（useWriteGuard）正常**。

### 4.3 编辑记录 ✅
- 双击「名称」单元格 → 进入编辑态（activeElement=INPUT，值「测试数据」）→ 写入「QA编辑验证」→ Enter → 网格立即显示；API 确认持久化。
- 证据：31-edit-cell.png。

### 4.4 批量选择 → 批量条 → 批量删除 → 撤销 → 恢复 ✅
1. 勾选 2 行 → 工具栏被**替换**为批量条：「已选 2 条 | 选择全部 N 条 | 批量修改字段… | **删除 2 行** | 取消选择」（R-I-12 替换式、R-I-14 带影响条数）。证据：33-bulk-bar.png、41-bulk-bar.png
2. 点「删除 2 行」→ 确认弹窗：「删除 2 行记录 | 记录会先进入回收站，30 天内可恢复。| 取消 | **删除 2 行记录**」——主按钮为具体动词（R-D-24 ✓）。证据：42-delete-confirm.png
3. 确认 → 右下角绿色 toast「✓ 已删除 2 行」+「撤销」按钮（R-D-20/21/22 ✓，6s 窗口）。证据：43-delete-toast.png
4. 点「撤销」→ toast「✓ 已恢复 2 行」；API 复核 3 条记录全部恢复 ✅。证据：44-after-undo.png
5. **缺陷 D-4**：撤销成功后网格未即时 refetch，状态条仍显示「共 1 条 · 已加载 1 条」且内容区空白，与真实数据（3 条）不一致，需手动刷新。

### 4.5 L1 折叠/展开 + 刷新保持 ✅
- 「收起导航」→ L1 宽 224 → **56**；`reload` 后仍 56（localStorage 记忆 ✓）；再展开 → 224。
- 证据：55-l1-collapsed.png、56-l1-reexpanded.png。

### 4.6 L1/L2 选中态 ✅
- 截图 03-table-view.png（1600 宽实拍）：当前导航项为**白底圆角卡片 + accent 蓝字**（`bg-white` + `rounded-gx-lg` + `text-gx-accent` + `font-semibold`）；**无左侧 3px 色条**（DOM 检查 `border-l-2` 子元素 = false）。
- L2 当前表项带 ✓ 勾选标记。

### 4.7 行尾三点 ⚠️（部分不符合）
- L2 导航列表项三点：20×20 占位 ✓（宽度实测 20px，不跳动）；菜单打开时按钮仍可见（opacity=1）✓。
- **不符合**：① 默认态 opacity=1（规范要求默认隐藏、hover 显示）；② **网格数据行没有行尾三点菜单**（`GridRow.tsx` 仅实现「展开记录」，无三点；规范 C.6/R-N-11 要求）。记录为缺陷 D-3。

### 4.8 导入向导四步 ✅
- L2 表级操作行「导入」→ 弹窗「导入 CSV」：横向步骤条「**① 上传 → ② 字段映射 → ③ 确认 → ④ 执行与结果**」，当前步 accent 高亮（R-I-17/22 ✓）。
- 上传 CSV（2 行）→ 实际导入成功：记录 14→16，toast「✓ 导入成功：新增 2 条」。
- 证据：62-import-step2.png（含步骤条与导入结果同框）。

### 4.9 导出对话框 ✅
- L2「导出」→ 触发浏览器下载 `table-<tableId>-<viewId>.csv`（下载事件捕获成功）。证据：66-export-download.csv。

### 4.10 全局搜索 ✅（⌘K 未验）
- 点击顶栏搜索框 → 行内弹层；输入「测试」→ 返回库/表/文档/画布命中。
- 证据：57-global-search.png、58-global-search-results.png。
- ⚠️ ⌘K 快捷键在 headless 环境未能触发（Meta+k 无响应），未覆盖（§8）。

### 4.11 知识库链路 ✅
1. `/kb` →「新建知识库」→ 弹窗（名称输入 + 取消/创建）→ 创建成功跳 `/kb/:id`。证据：70-kb-create.png
2. 「新建文档」→ 进入编辑器；三态 Tab「编辑/源码/预览」存在（C.6 ✓）；contenteditable 输入「QA验收测试内容第一段」成功；右上「保存中」自动保存流转。证据：72-doc-editor.png、73-doc-saved.png
3. 删除：文档卡片三点/删除入口在自动化定位下未命中，改走 API DELETE（**UI 删除入口未能验证**，见 §8）；文档进入回收站。
4. 回收站：列表显示「未命名文档 | 找回 | 彻底删除」→ 点「找回」→ 回收站清空，DB 复核 `deletedAt=null`（恢复成功 ✅）。证据：75-kb-trash.png、76-kb-restored.png

### 4.12 分享 / 加入 ⚠️
- 库分享链接创建成功（API 返回 token）。`/join/:token` 正常渲染「已加入 Base」✅（21-join.png）。
- 文档公开分享 `/s/:token` 匿名可访问，正文完整 ✅（23-public-share.png）。
- **缺陷 D-2**：分享 API 返回的 `url` 字段为 `/share/{token}`，但前端路由表无 `/share/:token` 路由（`App.tsx` 仅 `/join/:token` 与 `/s/:token`）——该链接命中 `*` 兜底路由被重定向至首页。UI 实际复制给用户的链接未复核（§8）。
