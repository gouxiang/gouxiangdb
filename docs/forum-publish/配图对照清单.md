## 上传小贴士

- 论坛编辑器一般支持直接拖拽 / 粘贴图片，按正文里的 **【配图 01】→【配图 11】** 顺序逐张替换标记即可。
- 若论坛对单图宽度有限制，这些图均为 16:10 横图，上传后选「原图 / 大图」宽度展示效果最好。
- 建议正文里的一级、二级标题用论坛编辑器自带的「标题」样式，列表用自带列表，`Ctrl/⌘+K`、`v0.2.3`、`fpk` 这类可按需用「行内代码」样式。
- 文末「安装方式小结」的步骤保持有序列表格式。
