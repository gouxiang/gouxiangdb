# 构想工作台 · 一款跑在飞牛 NAS 上的「智能表格 + 知识库 + 画布」一体化工作台

大家好，分享一个我们自己打磨了挺久的自托管工具——**构想工作台**（应用包名 `gouxiangdb`）。

一句话介绍：**它把「多维表格 + 团队知识库 + 白板画布」三件事做进了一个应用，完整跑在你自己的飞牛 NAS 上，数据全部存在本地，不上云、不订阅、不按人数收费。**

适合这样的你：

- 想用飞书多维表格 / Airtable / Notion，但**不想把团队数据放到别人服务器**；
- 小团队、工作室、家庭，需要一个能管项目、管客户、写文档、沉淀知识的地方；
- 喜欢折腾自托管，希望**装一个 fpk 就完事**，不用自己配数据库和反代。

下面按功能介绍，配了实际界面截图，文中的 **【配图 XX】** 就是建议插图的位置，图片文件我按 `01～11` 编好号了，对照着传即可。

## 一、安装与登录

飞牛应用中心「手动安装」上传 fpk 即可，提供 **x86 和 arm 两个架构**的包，装好后从桌面卡片直接打开。

首次打开是登录 / 注册页。第一个注册的账号自动成为这个工作台的所有者（超级管理员），后面的成员由管理员邀请或创建。整个应用是 Web 界面，电脑、平板、手机浏览器都能用，界面会自适应。

## 二、智能表格：30 种字段，一块表就是一个轻量业务系统

核心是「智能表格」。和普通电子表格不同，它的每一列都有明确的类型，目前支持 **30 种字段**：文本、数字、货币、百分比、单选 / 多选、日期、人员、评分、复选框、附件、关联、查阅、聚合、公式、自动编号、系统字段（创建人 / 创建时间等）……

下图是一个「研发项目管理」库里的**需求池**。可以直观看到：

- **单选字段**用彩色标签显示状态（待评审 / 已立项 / 开发中 / 已上线）；
- **优先级** P0～P3 用颜色区分轻重缓急；
- **人员字段**直接显示成员头像；
- **百分比字段**显示完成进度，日期、长文本各就各位；
- 顶部可以随时切换不同视图、做筛选 / 分组 / 排序 / 行颜色。

【配图 02：智能表格网格视图 · 需求池】

一个「库」（数据库）里可以建多张表。这个研发库里除了需求池，还有一张**缺陷跟踪表**，并用「关联」字段把缺陷和它对应的需求串了起来——点开一条需求，就能看到关联的所有缺陷。

## 五、团队知识库：文档、版本历史、公开分享

除了表格，每个工作台还自带一个**知识库**，用来写文档和沉淀经验。编辑器支持富文本 / Markdown，标题、列表、待办、表格、引用块都有，左侧带悬浮大纲目录。

【配图 08：知识库文档 · 产品发布流程】

文档能力上有几个很实用的点：

- **自动保存 + 版本历史**：每次保存形成一个命名版本，改错了可以一键查看历史版本、回滚；
- **公开分享链接**：一篇文档可以生成只读 / 可编辑的分享链接，发给团队外部的人看，不用给他开账号；
- **文档里能嵌入表格和画布**：写方案时直接把一张实时数据表或一块白板插进正文，数据更新，文档里跟着变。

## 七、企业级能力：组织架构、角色权限、审计

虽然是自托管小应用，但它按正经的企业协作系统来设计权限：

- **通讯录 + 部门架构**：可以建产品部 / 研发部 / 测试部，把成员挂到部门下；
- **角色体系**：自带超级管理员、管理员、受限成员等角色，也能自定义角色；
- **细粒度授权**：权限可以精确到库 / 表 / 文档，支持字段级、行级控制（比如成员只能看到自己负责的需求）；
- **操作审计**：关键操作都有审计记录。

## 九、关于数据和更新

- **数据完全本地**：后端是 Node + SQLite，所有数据库文件、上传的附件都存在你 NAS 选定的存储空间里，不上传任何第三方；
- **升级不丢数据**：应用内支持检查更新、在线升级，升级走数据库迁移并自动备份，卸载重装数据也保留；
- **轻量**：单进程同时提供网页和接口，内置数据库，不依赖外部 MySQL / Redis，fpk 一键装好即用。

## 安装方式小结

1. 下载与你 NAS 架构匹配的 fpk（**x86 或 arm，别下错**）；
2. 打开飞牛「应用中心」→「手动安装」→ 选择 fpk → 选安装存储空间；
3. 装好后从桌面卡片打开，第一个注册的账号即为管理员；
4. 浏览器打开即用，建议用 Chrome / Edge / Safari 最新版。
