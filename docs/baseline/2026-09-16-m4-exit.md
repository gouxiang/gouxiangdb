## 4. 三层就绪门现状（出口姿态，硬事实）

configAuthz.ts 在 M4 全程零默认翻转（S10 复验 configAuthz.ts 零 diff）：

| 常量 | 出口值 | env=on 时真实效果 |
|---|---|---|
| AUTHZ_ENFORCE_READY（七守总门） | **false** | on 被 effectiveAuthzMode 降级为 shadow + 一次 warn；七守无 enforce 生产分支 |
| FIELD_MASK_ENFORCE_READY | true | 读原始 env，on 即五出口真实下推（只减不增） |
| NAV_PRUNE_ENFORCE_READY | true | 读原始 env，on 即 tree/menu 剪枝 + 面包屑中性截断（只减不增） |

出口发布建议：**代码默认 off；生产建议值 shadow**（部署 env 显式设定）。
七守资源可达性切到引擎为权威，需要总监按五前置下令 + 一个含 enforce 接线
与总门翻转的独立构建切片（runbook authz-engine-flip-on.md 第 0 步），
不属 M4。

## 5. 规模与翻转证据（引用 S10 gate，自核口径一致）

详见 2026-09-16-m4-gate.md，出口确认项：

- 夹具 500 用户 / 31 部门（6 层）/ 10000 nav 节点 / 约 3000 策略。
- scope 客体 SQL 定数：非 owner 4 条、owner 3 条；decide 冷决策 3 条，
  同版本链缓存命中 1 条；creator 实体点查至多 1（进程内缓存命中为 0）。
- P95 区间（同机两次门运行）：decide 冷决策 0.36-0.41ms（n=252）、
  scope 万节点 41.8-44.0ms（n=21），均远低于 p95<500ms 团队线。
- scope<->decide 12000 次布尔对拍 0 差异；decide 四物理 SQL EXPLAIN 全
  SEARCH INDEX，零裸 SCAN，零新增索引（既有 auth_policies_node_idx 被选中）。
- policyVersion bump 全仓仅两处写事务（PUT policies 成功、继承实翻），
  读链路零 update。
- 三态翻转演练 s10-flip-drill 5 例：off 基线 -> shadow 双零 -> on 语义
  28 格（七守 x 四主体）与旧守卫期望全等 -> 反向 shadow 插桩 OVERALLOW/
  OVERDENY 分类正确且 HTTP 行为不变 -> 回 off 逐值恢复、权威行保留。

## 6. 升级等价与对账（S10 自核）

- s10-ac-upgrade-20x20：v0.1.0 风格旧三库种子 -> reconcile --apply ->
  20 主体 x 20 节点 400 格引擎 r 判定与旧三表 oracle 全等，reconcile 0 漂移。
- reconcile 码表以实现为准：A1_UNMAPPABLE_ROLE/A1_MISSING_POLICY/
  A2_ACTION_MISMATCH/A3_MANUAL_MATCHES_LEGACY（只报）；
  B1_ORPHAN_PROJECTION/B2_BROKEN_NODE/B3_MISSING_USER；
  C1_BAD_ACTION/C2_DANGLING_FIELD/C3_DANGLING_DEPT|ROLE/
  C4_DUPLICATE_POLICY/C5_CONDITIONS_PRESENT（只报）。
  --apply 修 A1/A2/B1/B2/B3，连跑第二次 no changes。
- D 类（逐请求决策漂移）不在脚本内，由 shadow 运行时 driftRegistry
  （DRIFT_OVERDENY/DRIFT_OVERALLOW）承担；runbook authz-drift-and-incidents
  §1 已按此实现写清分工。
- S11 出口补丁 s11-kb-single-row-equiv：kb 下钻 5 层（nav depth 2..6，
  达 N>=4），9 doc + 1 canvas 共 10 内容叶；viewer/editor 单行 kb 投影态
  与逐 doc 物化态对 2 成员 x 10 叶 x 6 动作（r/c/u/d/comment/manage_share，
  manage_schema 对 doc/canvas 非法不取）= 120 格全等；非成员 60 格全 deny；
  direct kb_doc_acls 例外用户仅最深 doc 五动作 allow、其余 54 格 deny；
  含切断中间容器继承的存活 sanity，并以变异自证全等用例在分叉时变红。
