## 7. 已知限制与遗留（如实登记，不美化、不省略、不带到 M5 冒充完成）

1. **arm64 未做真机**：用户 2026-09-17 授权的对计划「x86 与 arm 各一台」的**偏离**；arm 仅 CI 交叉构建冒烟
   （linux/arm64 加载 vec0 + 1 次 KNN），**性能数字【未实测】**，不得以 x86 数字近似。
2. **S13 容量结论（Tier-L x86_64 实测，来源 `2026-09-17-m5-gate-tierL.md`）**：hybrid p95 = 1k≈20ms /
   10k≈0.65s / 100k≈**14.6s**；外推流畅上限≈**6.5k chunk**；瓶颈=**vec0 无 ANN 暴力全扫 ∝ N**；
   **收紧 scope 与调 k 实测无效（两条负结论）**；关向量 fts-only ≈4×（10k≈0.15s 达标 / 100k≈3.7s）；
   RSS 有界 105→187MiB（**内存非瓶颈**）。**Tier-S「1万–10万流畅」在 hybrid/vector 路未达标**
   （按计划要求以参考画像 + 降级发布结论交付，非偏离）。
3. **ANN（LanceDB/等价）评估登记为下里程碑 ADR 候选**：已命中计划 §13「真机 P95 持续超标」分支；
   本里程碑**不实施**（编号与落笔留 S14 ADR / 下里程碑）。
4. **真机画像口径提醒**：Mem 5.9GB 略宽于 Tier-L 4GB 目标；`rotational=1` 报告机械盘但宿主真实介质未知
   → 磁盘维度结论偏乐观、待真机复核。
5. **既存 flaky**：`s10-ac-upgrade-20x20.test.ts:136` 建议随下个里程碑修（放宽该用例显式 `timeout`
   或改批量），否则影响后续出口门稳定性。
6. **不加自动降级 guard**（会改 `degraded[]` 冻结枚举/行为契约），改为**指引式**（文档 + 设置面板提示语）；
   若未来要加，需单独 ADR。
7. **M3 遗留两项仍在**（如实列出，带 M5 未完成）：
   - task#158 `buildExpectedNodes + reconcileNodesTx N+1 批量化`（nav 10 万节点 P95 门）；
   - task#175 `M3-S11 部署链路接入 reconcile-nav path 重算`（防升级后导航失效）。
