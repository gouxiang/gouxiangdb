## 4. M6 不能动的契约（引用计划 §3，此处只摘要）

1. 旧 `/api` 与 v1 既有端点字节不变（S0 已锁 4 条）。
2. M4 契约只消费不改（`resolveVisibleNodeIds`/`buildVisibleScopeSql`/`engine.decide`/`fieldCapability`）；
   **S3 开工逐点复核 M4 实际导出名**，偏差走薄适配，不改 M4 文件。
3. **MCP 工具不接旧守卫**：`mcp/**` 内 grep `requireCan|from "../../guards"|prisma\.` 命中即打回（PAT 自身存储与审计例外）。
4. 每请求边缘重认证、无会话信任；PAT 首版不缓存。
5. 存在性不泄漏二分口径（UNKNOWN_TOOL vs FORBIDDEN_*），S3 写 golden。
6. 密钥/token 零泄漏（明文仅创建一次；GET 永不回 hash；审计 `redactSecrets`）。
7. 协议合规面（Content-Type/Accept、版本协商、`confirm:true`）。
8. 配额契约（limit≤200 / op≤100 / 文本≤100KB / 10MB / 30s 超时）。
9. 版本兼容/回滚（SDK 进 external；回滚 = 路由摘除 + 迁移保留）。
10. M0–M5 回归不回退（默认姿态无 MCP 客户端时零额外定时器/零外网）。
