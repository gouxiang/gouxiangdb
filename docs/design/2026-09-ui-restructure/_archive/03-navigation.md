## 0. 相对 v2.0 的变更点

| # | 变更 | 说明 |
|---|---|---|
| 1 | **底部三项固定对齐** | 「通讯录 / 后台设置 / 回收站」从上方顺序中移出，改为**固定在菜单容器底部**的独立区块，与上方可滚动菜单区分离；三者顺序与间距不变，最底部仍为「用户卡片」 |
| 2 | **工作区下只展示数据库** | 「工作区」节点下只列出各数据库（产品中心 / 技术中台 / 运营中心），**不再展开库内数据表**；数据表全部下沉到二级面板 |
| 3 | **新增「知识库」模块** | 补回缺失的知识库入口，层级与「工作区」同级（同属上区），含「产品文档 / 技术规范」 |
| 4 | **L2 简化为「数据表列表」** | 点击某数据库后，L2 只展示该库的数据表清单；**移除字段列表、视图切换入口、列视图入口**（视图切换与新建视图已在右侧视图标签条提供） |
| 5 | **数据表行新增竖向三点「⋯」** | 每个数据表名称后固定显示竖向三点，点击弹出：编辑 / 重命名 / 复制 / 导出 / 删除 |
| 6 | **视图标签条新增竖向三点「⋯」** | 右侧表格上方视图菜单区增加竖向三点（非横向），点击弹出当前视图的编辑菜单 |
| 7 | （沿用 v2.0）顶栏左侧为 Logo | 顶栏无数据库切换控件；库 / 表选择只在一级「工作区」与二级面板完成 |
| 8 | 名称沿用人工修订 | 「成员与权限」→「通讯录」、「工作区设置」→「后台设置」；下区不再保留「用户 / 管理 / 设置」三段段头，三项直接成组 |

## 1. 壳层结构（不变）

`WorkspaceShell` 单壳：`TopBar` + `L1 一级导航` + `L2 二级面板` + `ContextBar` + 内容区。

| 层 | 宽度 | 底色 |
|---|---|---|
| TopBar | 全宽，h56 | `gx-surface` |
| L1 一级导航 | 224（可折叠 56） | `gx-nav1` #E9EFF9 |
| L2 二级面板 | 240 | `gx-nav2` #F4F8FD |
| ContextBar | h40 | 内容区 |
| 内容区 | flex-1 | `gx-canvas` #F7F8FB |

L1 内部竖向分区：**新建区（hug）→ 导航列表（fill，可滚动）→ 底部固定区（hug）→ 用户卡片（hug）**。

## 2. L1 一级导航（完整结构）

```
┌───────────────────────────────────────┐
│ ＋ 新建                                │ ← 主按钮，全宽
│                                       │
│ ── 上区：可滚动菜单区 ───────────────── │
│  个人门户                              │ ← 段头
│    ⬜ 工作台首页                        │
│    🟠 我的待办                         │
│    🟣 我的收藏                         │
│  工作区                                │ ← 段头
│    🗂 产品中心          （选中·白卡）    │ ← 只列数据库，不展开表
│    🗂 技术中台                          │
│    🗂 运营中心                          │
│  知识库                                │ ← 段头，与「工作区」同级
│    📘 产品文档                          │
│    📘 技术规范                          │
│                                       │
│         （弹性留白 → 随内容滚动）        │
│ ───────────────────────── 分隔线 ───── │
│ ── 下区：底部固定区（不随滚动） ───────── │
│    📇 通讯录                            │
│    ⚙  后台设置                          │
│    🗑 回收站                            │
│ ─────────────────────────────────────  │
│  ( 头像 ) 戴静              ⋯           │ ← 用户卡片，始终是最后一项
└───────────────────────────────────────┘
```

### 2.1 顶部操作区

| 元素 | 层级 | 点击行为 |
|---|---|---|
| **＋ 新建**（主按钮，36px） | L1 顶部 | 弹出新建菜单：数据表 / 文档 / 画布 / 文件夹；落入当前上下文（在数据库下则建到该库） |
| 用户卡片 | L1 最底部 | 点开头像菜单：个人资料 / 切换工作区 / 退出登录；`⋯` 同入口 |

### 2.2 上区 · 可滚动菜单区（靠上）

| 层级 | 菜单项 | 点击预期行为 | 附属按钮 |
|---|---|---|---|
| L1 段头 | 个人门户 | — | — |
| L1 | 工作台首页 | 路由到 `/`（概览卡片、统计、最近使用） | ⋯（固定到顶部 / 从导航隐藏） |
| L1 | 我的待办 | 打开「指派给我 / 我发起」的记录聚合列表 | ⋯（筛选条件、刷新） |
| L1 | 我的收藏 | 打开收藏的资产列表 | ⋯（管理收藏） |
| L1 段头 | 工作区 | — | — |
| L1 | **产品中心**（数据库，选中态） | 选中该库，**L2 切换为该库的数据表列表** | hover ⋯（新建数据表 / 导入数据 / 导出全库 / 数据库设置 / 成员与权限） |
| L1 | 技术中台（数据库） | 同上 | 同上 |
| L1 | 运营中心（数据库） | 同上 | 同上 |
| L1 段头 | 知识库 | — | — |
| L1 | 产品文档 | L2 切换为文档树（知识库模式） | hover ⋯（重命名 / 移动 / 分享 / 删除） |
| L1 | 技术规范 | 同上 | 同上 |

> 关键约束：**一级导航中不再出现任何数据表条目**。数据库是 L1 的叶子节点，数据表是 L2 的唯一内容。

### 2.3 下区 · 底部固定区（靠下，不随滚动）

| 层级 | 菜单项 | 点击预期行为 |
|---|---|---|
| L1 | 通讯录 | 成员列表 + 邀请成员（原「成员与权限」） |
| L1 | 后台设置 | 工作区基础信息、默认视图、字段类型开关、集成（原「工作区设置」） |
| L1 | 回收站 | 已删除资产列表，可恢复 / 彻底删除 |

> 三项之间保持 34px 行高 + 2px 间距，与上方滚动区以 `gx-hairline` 分隔线隔开；窗口高度变化时该区块始终贴底。

### 2.4 状态规范（沿用前版）

- 选中：白色浮起卡片（`gx-surface` + `shadow-sm`）+ 文字 `gx-accent` 500。
- 未选中：文字 `gx-text-2`，hover 底 `gx-hover`。
- 禁用：`opacity .5` + `cursor not-allowed`；`soft_dangling` 隐藏、`broken` 显灰。
- 段头：`gx-11`/500/`gx-text-hint`；缩进 `8 + depth × 14`。

## 3. L2 二级面板（选中数据库时＝数据表列表）

```
┌────────────────────────────┐
│ 🗂 产品中心              ⋯   │ ← 头部：当前数据库名 + ⋯
│ 🔍 筛选记录                  │ ← 搜索 / 筛选框
│ [导入] [导出] [分享]         │ ← 操作按钮行
│ ── 数据表 12 ─────────────   │
│   ▦ 需求池        ⋮（选中）  │ ← 名称 + 竖向三点
│   ▦ 迭代计划          ⋮      │
│   ▦ 缺陷跟踪          ⋮      │
│   ▦ 版本记录          ⋮      │
│   ▦ 埋点日志          ⋮      │
│   ▦ 竞品分析          ⋮      │
│   ▦ 客户反馈          ⋮      │
│   ▦ 测试用例          ⋮      │
│   ▦ 上线清单          ⋮      │
│   ▦ 接口清单          ⋮      │
│   ▦ 数据字典          ⋮      │
│   ▦ 变更日志          ⋮      │
│   ＋ 新建数据表               │
└────────────────────────────┘
```

| 元素 | 层级 | 点击预期行为 | 附属按钮 |
|---|---|---|---|
| 头部（数据库名） | L2 | 留在当前库；`⋯`＝数据库级菜单（重命名 / 新建数据表 / 导入 / 导出 / 数据库设置 / 删除） | ⋯ |
| 搜索框 | L2 | 过滤**数据表名称**（库内检索，不筛记录） | — |
| 导入 / 导出 / 分享 | L2 | 库级操作：导入建表 / 导出全库 / 分享协作（链接权限、邀请协作者） | — |
| 数据表行 | L2 | 选中该表，右侧内容区切到该表；L2 头部与 ContextBar 同步 | **竖向三点 `⋮`** |
| 行内 `⋮`（竖向三点） | L2 | 弹出该表菜单：**编辑 / 重命名 / 复制 / 移动到 / 导出 / 删除** | 常驻显示，hover 加深 |
| ＋ 新建数据表 | L2 | 在当前库内新建数据表 | — |

> **已移除（v2.0 遗留）**：视图列表（表格 / 看板 / 日历 / 画廊）、新建视图、字段列表、管理字段、列视图入口。
> 视图切换与新建视图统一由右侧 **ContextBar 视图标签条**承担。

## 4. ContextBar 视图标签条（右侧表格上方）

```
表格视图   看板   日历   画廊          ⋮   ⚙   ＋
└─ 选中 ─┘                          ↑新增竖向三点
```

| 元素 | 点击预期行为 |
|---|---|
| 视图 Tab | 切换视图（表格 / 看板 / 日历 / 画廊 / 表单） |
| **`⋮` 竖向三点** | 当前视图菜单：编辑视图 / 重命名 / 复制 / 设为默认 / 删除 |
| `⚙` 视图设置 | 打开视图配置抽屉（筛选条件、分组、排序、字段显隐、行高） |
| `＋` 新建视图 | 新建视图 |

> `⋮` 必须是**竖向**三点（三个圆点纵向排列），不得使用横向「…」。

## 5. 顶栏

| 位置 | 元素 | 说明 |
|---|---|---|
| 左 | **Logo**（标识块 + 「构想工作台」15/600） | 替代原数据库切换控件；点击回工作台首页 |
| 中偏右 | 全局搜索 300×34 | 搜索记录、文档与画布（`⌘K`） |
| 右 | 快捷键提示 · 通知 · 头像 30 | 头像点开＝用户菜单（与 L1 用户卡片同入口） |

> 顶栏不再出现库名 / 切换箭头——数据库与数据表的选择**只在 L1 工作区 + L2 面板内完成**。
