# 02 · 视觉设计系统

## 1. 设计基调与来源说明

本轮选定的风格模板是 **Apple 营销站基因**（摄影优先、深色全屏导航、56px 大标题、pill 大按钮）。它是面向「让产品自己说话」的营销语言，**不能直接套用在数据密集的后台工具上**。处理方式：

**保留模板的底层气质，替换它的尺度。**

| 保留（气质） | 替换（尺度） |
|---|---|
| 极度克制，无装饰性渐变 | 字号基准下潜到 13px，最小 11px |
| chrome 零阴影，只有浮层有阴影 | 圆角 4–12px（营销站的 18px 不适用） |
| 全站唯一强调色 | 间距 4px 基准（营销站的 12/24px 不适用） |
| hairline 发丝分隔（1px 极淡） | 导航用浅色侧栏，不用全黑 global-nav |
| 系统字体栈 | — |

## 2. 配色规范

### 2.1 语义色板（新 token 名 `gx-*`）

| Token | 值 | 用途 | 替代的旧 token |
|---|---|---|---|
| `gx-canvas` | `#F5F5F7` | 页面底、一级导航底 | `gx-bg`（原 `#F1EFE8` 暖米） |
| `gx-surface` | `#FFFFFF` | 主面板、顶栏、卡片、输入框 | 不变 |
| `gx-surface-alt` | `#FAFAFC` | 表头、聚合栏、状态栏、斑马纹 | `gx-table-header`/`gx-zebra`（原与页面底同值） |
| `gx-hover` | `#F2F2F4` | 行/项 hover | `gx-row-hover` |
| `gx-selected` | `#EAF2FC` | 选中底、激活工具按钮底 | `gx-accent-bg` |
| `gx-accent` | `#378ADD` | 品牌主色、主按钮、选中态文字、指示条 | **保留现有品牌色** |
| `gx-accent-hover` | `#2A72BE` | 主按钮 hover | 新增 |
| `gx-text-1` | `#1D1D1F` | 一级文本 | `gx-text-primary`（原 `#26215C` 深紫） |
| `gx-text-2` | `#48484A` | 二级文本、表头、未激活工具按钮 | `gx-text-secondary`（原紫色 `#534AB7`） |
| `gx-text-3` | `#6E6E73` | 三级文本、未选中导航 | `gx-text-tertiary` |
| `gx-text-hint` | `#8E8E93` | 占位符、段头、辅助说明 | 不变（值由 `#888780` 微调） |
| `gx-text-disabled` | `#B4B4B9` | 禁用文本、面包屑箭头 | 新增 |
| `gx-hairline` | `#EBEBEF` | 表格网格线、面板分隔线 | `gx-separator` |
| `gx-border` | `#DFDFE4` | 输入框、卡片、Popover 边框 | 不变 |
| `gx-success` / `-bg` | `#1D9E75` / `rgba(29,158,117,.10)` | 成功、已保存 | 保留 |
| `gx-warning` / `-bg` | `#BA7517` / `rgba(186,117,23,.10)` | 警告、未保存 | 保留 |
| `gx-danger` / `-bg` | `#E24B4A` / `rgba(226,75,74,.10)` | 危险操作、删除 | 保留 |

**三层底色逻辑**（解决现状「四个 token 同值、无层级」的问题）：

```
gx-canvas   #F5F5F7   ← 最外层（导航）
gx-surface-alt #FAFAFC ← 表格chrome（表头/聚合/状态栏）
gx-surface  #FFFFFF   ← 数据面（最亮、最前）
```

### 2.2 选项色板（表格单选/多选、行颜色）

沿用现有 12 色 `COLOR_PALETTE`，语义映射：

| 选项 | 底色 | 文字色 |
|---|---|---|
| 进行中 | `#D3F0E4` | `#0F6E56` |
| 已完成 | `#DCE7F5` | `#378ADD` |
| 待评审 | `#FBE9D0` | `#BA7517` |
| 待规划 | `#E5DEEB` | `#534AB7` |
| 已搁置 | `#F7E1D7` | `#993556` |

优先级用纯文字着色：P0 `#E24B4A`、P1 `#BA7517`、P2 `#8E8E93`。

### 2.3 字段类型色（表头图标）

沿用现有 `FIELD_TYPE_COLOR` 27 项，不变（如 text `#8B5CF6`、number `#3B82F6`、date `#A855F7`、user `#06B6D4`、links `#22C55E`、select `#14B8A6`）。

## 3. 字体与字阶

- 字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`
- 全站正文 13px / 行高 1.5，数据密集场景不做 14px 基准。

| Token | px | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| `gx-11` | 11 | 1.5 | 400/500 | 段头、状态栏、徽标、辅助说明 |
| `gx-12` | 12 | 1.5 | 400/500 | 表头、工具按钮、Tab、选项胶囊、次级按钮 |
| `gx-13` | 13 | 1.5 | 400/500/600 | **基准**：正文、导航项、单元格 |
| `gx-14` | 14 | 1.5 | 500/600 | 弹窗标题、文档标题输入框 |
| `gx-16` | 16 | 1.5 | 600 | 页面标题（KB 首页库名） |
| `gx-20` | 20 | 1.4 | 600 | 大标题（设置页分区） |
| `gx-24` | 24 | 1.3 | 600 | 空态主标题（仅个别页面） |

> **去掉 `gx-15`**（现状 6 处引用但档位缺失），归并到 `gx-14` / `gx-16`。

## 4. 间距体系（4px 基准）

| Token | px | 典型用途 |
|---|---|---|
| `gx-xxs` | 2 | 图标与徽标微调 |
| `gx-xs` | 4 | 图标与文字、Tab 间距 |
| `gx-sm` | 6 | 按钮内图标-文字 |
| `gx-md` | 8 | 导航行、单元格内边距、面板内间距 |
| `gx-lg` | 12 | 面板水平内边距、卡片内边距 |
| `gx-xl` | 16 | 区块间距 |
| `gx-xxl` | 20 | 卡片组间距 |
| `gx-3xl` | 24 | 页面级区块间距 |

现状大量使用 Tailwind 原生 `px-2/py-1.5`，重构时**统一收敛到 `gx-*` token**（值基本一致，主要是语义化）。

## 5. 圆角

| Token | px | 用途 |
|---|---|---|
| `gx-sm` | 4 | 选项胶囊、勾选框、徽标 |
| `gx-md` | 6 | 按钮、输入框、导航行、工具按钮、Tab |
| `gx-lg` | 8 | 卡片、Popover、看板列 |
| `gx-xl` | 12 | Modal |
| `gx-pill` | 9999 | Badge、头像、分段控件选中块（**补齐缺失档位**） |

## 6. 阴影与层级

- **chrome 零阴影**：导航、顶栏、工具栏、表头一律无阴影，用底色与 1px 发丝线分层。
- 阴影只用于浮层，且须接入 `gx-shadow-*` token（修复现状未映射的问题）：

| Token | 值 | 用途 |
|---|---|---|
| `gx-shadow-sm` | `0 1px 2px rgba(0,0,0,.04)` | hover 卡片 |
| `gx-shadow-lg` | `0 4px 12px rgba(0,0,0,.10)` | Popover、Menu |
| `gx-shadow-xl` | `0 8px 24px rgba(0,0,0,.12)` | Modal、Drawer |

- z-index 统一走 `gx-z-*`（现有定义保留）：drawer 400 / modal 800 / popover 900 / toast 1000；表格 sticky：表头 10、行首 20、表头行首 30、编辑层 30。

## 7. 网格与密度

| 密度 | 行高 | 适用 |
|---|---|---|
| 紧凑 | 32 | 记录 > 1000、开发者视图 |
| **常规（默认）** | **44** | 所有视图 |
| 宽松 | 64 | 内容较长的记录 |

预设计稿基准分辨率 **1440×900**，最小支持 1024（二级导航在此断点以下隐藏）。
