# 09 · 设计补全方案（含边界与异常状态）

> 版本 v1.0 ｜ 2026-09-18 ｜ 状态：**待确认**
> 依据：`07-interaction-inventory.md`（679 条交互）× `08-gap-analysis.md`（遗漏与裁决）。
> 定位：把**每一个已存在的交互**都纳入设计，补齐此前只画了"正常态"的部分。
> 与 `03`/`04`/`05` 的关系：**保留**其已定规格，本文档只做**增量补全**；冲突处以本文档为准并回写原章节。
> 只做设计，不动业务代码。

## 0. 总则：每个交互都要有六态

设计稿此前只画了 **默认态 / 悬停态 / 选中态**。从本轮起，凡是有数据读写或跳转的交互，设计稿必须同时给出：

| 态 | 必须回答的问题 | 通用规格 |
|---|---|---|
| **① 默认** | 长什么样 | 见 `05` |
| **② 悬停 / 聚焦** | 悬停与键盘聚焦是否等价 | 悬停＝`gx-hover`；聚焦＝`gx-accent` 2px 外环，**两者必须同时可用**（禁用 hover-only） |
| **③ 进行中** | 提交/加载中按钮与区域怎么表现 | 按钮：spinner 替换图标位 + 强制 disabled；区域：骨架屏（≥3 行）或内联 spinner，**禁止整页 Spinner** |
| **④ 成功** | 反馈落在哪 | 就近：窗内成功条 or 行内；远处：Toast。二者**不重复**（见 §2.4） |
| **⑤ 失败** | 错误落在哪、能否重试 | 字段级错误在字段下方；操作级错误在触发点就近；**必须带重试** |
| **⑥ 不可达** | 无权限 / 已失效 / 被锁定 / 数据量超限 | 见 §1.4 / §4，禁用必须**可发现原因**（图标 + Tooltip，不用原生 title） |

## 1. 全局状态与异常态规范（新增）

### 1.1 加载态

| 场景 | 规格 | 说明 |
|---|---|---|
| 首屏 / 整页 | **骨架屏**：容器结构灰块（圆角 6，`gx-surface-alt`），≥3 行，1.2s 微光扫过 | **全仓现状无骨架屏**，本轮补齐 |
| 局部刷新（列表、面板） | 内联 Spinner(16) + 保留旧内容 + `aria-busy="true"` | 禁止清空内容后转圈 |
| 按钮提交中 | spinner 替换图标位 + 强制 disabled + 文案保持 | 现状有 4 处只 disabled 无 spinner，需补 |
| 长时间（>3s，如重建索引、导入） | 进度条 + 百分比 + 可最小化 | 新增 Progress 组件（§11） |
| 探活（navV2） | **必须加超时兜底**：8s 后显示「初始化较慢…」+ 重试按钮 | 现状卡住即永久转圈 |

### 1.2 空态（统一为 `EmptyState` 一个组件，收敛现有两套 + 第三类内联卡）

```
┌───────────────────────────┐
│        （图标 48 · hint）    │
│      主文案（gx-14/500）     │
│   副文案（gx-12 · hint）     │
│      [ 主操作 ]  [ 次操作 ]   │  ← 可选，最多两个
└───────────────────────────┘
```

| 场景 | 主文案 | 副文案 | 操作 |
|---|---|---|---|
| 无数据 | 暂无记录 | 点击「新建记录」开始添加数据。 | 新建记录 |
| **筛选无匹配**（区别于无数据） | 没有匹配的记录 | 试试调整筛选或搜索条件。 | 清除筛选 |
| 无导航项 | 暂无导航项 | 数据库与文档会出现在这里。 | — |
| 无数据表 | 这个数据库还没有数据表 | 新建第一张表开始记录数据。 | 新建数据表 |
| 无分组 | 暂无分组 | 可在「设置 → 导航编排」中新建。 | 去设置 |
| 无匹配（浮层内） | 没有匹配的内容 | — | — |
| 无权限查看 | 没有访问权限 | 联系工作区所有者申请。 | — |

> **强制**：空态与错误态**不得共用同一文案**；「无数据」与「筛选无匹配」必须区分。

### 1.3 错误态

| 层 | 呈现 | 规格 |
|---|---|---|
| 字段级 | 字段下方 `gx-11` `gx-danger`；输入框边 `gx-danger`；`aria-invalid="true"` | 见 §6 |
| 操作级（就近） | 触发按钮上方一行红底条（`gx-danger-bg`/28/radius 6） | 带「重试」文字按钮 |
| 区域级 | 替换该区域，图标 + 文案 + **重试按钮** | 不允许只给一行灰字 |
| 全页级（ErrorBoundary） | 居中卡片 + 重试 + 可展开错误详情 | 现状已有，**需补**：不只包壳，抽屉/富文本/单元格各包一层 |

**错误文案三原则**：① 说清发生了什么 ② 说清用户能做什么 ③ **绝不出现 `API 404: xxx` 这类前缀与英文原文**。

### 1.4 无权限 / 降级 / 受限态

| 态 | 场景 | 呈现 |
|---|---|---|
| **无操作权限** | `canEditData` / `canManageSchema` 为假 | 见 §4 决策表 |
| **环境未开放** | `enterpriseOrg` / `authzManage` 门控关 | 「此功能未在当前环境开放」+ 说明如何开启（自助指引），**不要静默隐藏入口**（现状是隐藏，用户不知道功能存在） |
| **数据量降级 degraded** | 大表受限口径 | `ResultNotice` tone=warning，`role="alert"`，文案「数据量较大，当前为受限结果，精确统计需增加筛选条件。数据仍可正常查看与编辑。」（现状文案很好，**沿用并推广到全站**） |
| **结果截断 truncated** | 超 10000 条 / 候选满 50 / 列表硬截 200 | `ResultNotice` tone=info + 「结果共 N 条，当前仅显示前 M 条，请增加筛选条件缩小范围。」**现状 EntityPickerModal 硬截 200 无提示，必须补** |
| **对象已失效** | 菜单树 broken / 悬挂主体 / 内链失效 | 名称删除线 + hint 色 + 徽章「已失效」；菜单树编排态可一键清理 |
| **会话过期** | 401 | 见 §1.6 |
| **冲突** | 409 乐观锁 / 移动影响 / 继承影响 | 见 §3.3 |

### 1.5 网络与离线

| 态 | 呈现 |
|---|---|
| 断网 | 顶栏下方常驻 `gx-warning-bg` 横幅「网络连接已断开，操作将在恢复后自动重试」+ `navigator.onLine` 监听 |
| 请求超时 | 就近错误条 + 重试；**本轮需补 AbortController 与 timeout（目前全仓无）** |
| 5xx / 网关异常 | 区域级错误 + 重试；文案「服务暂时不可用，请稍后重试」 |
| 200 非 JSON（网关吞请求） | 识别为网关异常，**不得显示 `SyntaxError`** |

### 1.6 会话过期（401）重做

现状是 `window.location.assign` 硬跳，丢全部状态且无解释。改为：

```
┌──────────────────────────────────┐
│  （盾牌图标）                       │
│  登录状态已过期                     │
│  为保护数据安全，已退出登录。         │
│  [ 重新登录 ]                      │
│  重新登录后将回到当前页面            │
└──────────────────────────────────┘
```

- 用 SPA 路由跳转，不硬刷新；跳转前把当前 pathname + query 写入 `sessionStorage['gx-return-to']`，登录后回跳。
- 并发 401：延长冷却到当前跳转完成，而不是 3s 窗口；窗口内的后续 401 统一进入上面的着陆页，**不得静默**。

## 2. 反馈体系规范（新增）

### 2.1 Toast 补齐

| 项 | 现状 | 补齐后 |
|---|---|---|
| 变体 | success / error / info | **+ warning**（`gx-warning` 底、深色字 + 图标），用于"成功但有问题"（如导入 100 条成功 3 条失败、部分权限未生效） |
| 关闭 | 无 | 右侧 ✕，`gx-12`，hover 提亮 |
| 悬停暂停 | 无 | hover 暂停计时，移开后重新计时 |
| 撤销 | 无 | `toast(msg, {action:{label:"撤销", onClick}})`；删除类操作**必须带** |
| 堆叠 | 无限堆叠 | 最多 3 条，超出折叠为「还有 N 条通知」 |
| 时长 | 固定 3200ms | success 2400ms / info 3200ms / warning 4800ms / error 6000ms 且**默认不自动消失**（需手动关闭或点重试） |
| 无障碍 | 无 | `role="status"` + `aria-live="polite"`；error 用 `role="alert"` + `assertive` |

### 2.2 就近反馈（减少 toast 滥用）

| 位置 | 用于 |
|---|---|
| 字段下方 | 校验错误（§6） |
| 触发按钮上方红条 | 操作级失败 |
| 窗内成功条 | 弹窗内完成的动作（如邀请成功），**不再同时弹 toast** |
| 行内微态 | 单元格/行级保存：保存中（脉冲点）→ 已保存（✓ 淡出）→ 失败（红边框 + 重试） |
| Tooltip | 禁用原因、截断说明、图标含义 |

### 2.3 写操作三态（现状缺失，必须补）

```
空闲 ──▶ 保存中（按钮 spinner / 行内脉冲点）
          │
          ├─▶ 成功（✓ 淡出 1.2s / toast success）
          └─▶ 失败（字段红边 or 就近红条 + 【重试】+ 值回滚到服务端快照）
```

**关键**：现状 `updateConfig` / `commitValue` 失败**不回滚**，UI 与服务端不一致。设计规定：**任何乐观更新失败必须回滚并给出可见提示**。

### 2.4 「窗内反馈 vs 全局 Toast」分工规则

| 情况 | 用哪个 |
|---|---|
| 操作对象就在弹窗内（邀请、签发令牌、创建分组） | **窗内成功条**，弹窗不关或变为结果态；**不弹 toast** |
| 操作对象在背景列表（删记录、改视图配置） | Toast（带撤销） |
| 两者都有 | 只保留一个，优先就近 |

## 3. 危险操作确认矩阵（新增）

按 **不可逆程度 × 影响面** 两维分级，取代现状的随机强度。

| 级别 | 判定 | 确认形式 | 主按钮 | 取消按钮 | 现有归属 |
|---|---|---|---|---|---|
| **L0 无确认** | 可逆，且影响 1 个对象 | 无 | — | — | 重命名、改状态、收藏、保存配置 |
| **L1 Toast 可撤销** | 可逆但影响 1–N 个对象 | 执行 + Toast「已删除 N 行 **撤销**」 | — | — | 删除记录、批量删除、移除授权、移除成员 |
| **L2 标准确认** | 不可逆，影响 1 个对象 | Modal，标题＝动作名，正文＝后果 | danger「删除」 | 「取消」 | 删除数据表、删除视图、删除文档、清空表、吊销 PAT、删除分享链接 |
| **L3 输入确认** | 不可逆，影响整个容器 | Modal + **输入对象全名**才启用主按钮 | danger | 「取消」 | 删除 Base、删除知识库、注销账号 |
| **L4 双因子** | 不可逆，影响账号/全工作区 | 输入指定文字 **+** 当前密码；或影响面列表 + 豁免说明 | danger | 「取消」 | 注销账号（现状已是）、中断权限继承（现状已是） |
| **L5 影响面确认** | 服务端 409 驱动 | Modal + **影响面明细**（受影响成员 / 子树内容 / 菜单引用，支持分页展开）+ 豁免说明 | 按后果定 danger 或 primary | 「取消」 | 移动节点、中断/恢复继承 |

### 3.1 统一确认弹窗结构

```
┌────────────────────────────────┐
│ ⚠ 删除数据表「需求池」？          │  ← 标题＝动作 + 对象名
│                                │
│ 该表包含 1,284 条记录与 7 个字段， │  ← 后果：量化，不说"可能"
│ 视图配置会一并删除。              │
│                                │
│ ┌ 影响面 ────────────────────┐ │  ← 仅 L5 出现
│ │ 受影响成员        12 人      │ │
│ │ 子树内容          38 项      │ │
│ │ 菜单引用          5 处       │ │
│ └──────────────────────────┘ │
│                                │
│ 请输入「需求池」以确认：          │  ← 仅 L3/L4
│ [                        ]     │
│                                │
│            [ 取消 ]  [ 删除 ]   │  ← 主按钮＝动作实际后果
└────────────────────────────────┘
```

### 3.2 按钮语义规则

- **主按钮文案 = 该动作的实际后果**（「删除」「吊销」「确认中断」），**不用**「确定」「好的」。
- danger 语义只用于**造成损失**的动作；「确认恢复」「确认移动」这类增益/中性动作用 primary。
- 取消按钮统一「取消」；仅当取消后应该继续编辑时用「返回修改」。

### 3.3 409 驱动确认的 UI 契约（现状已有但无规范）

```
请求 → 409 + code + impact
     → 弹影响面弹窗（不报错）
     → 确认 → 原请求带 confirmed:true **重放一次**
     → 成功 → 关闭 + toast
     → 取消 → 什么都不做，**不重发**
```

要求：① 四个已知码（`MOVE_NEEDS_CONFIRM` / `INHERITANCE_CONFIRM_REQUIRED` / `NEED_CLOUD_CONFIRM` / `REINDEX_IN_PROGRESS`）各有一个专用弹窗；② 重放失败按普通错误处理；③ **弹窗内不得出现"M3 不改变权限继承"这类后端版本免责说明**（属于产品能力说明，应移到帮助文档）。

## 4. 权限门控决策表（新增）

现状"隐藏 / 禁用 / 整块替换"三种策略混用。统一规则：

| 情形 | 策略 | 理由 | 规格 |
|---|---|---|---|
| **用户可理解该能力存在，但当前不能用**（如无编辑权的新建记录、只读字段） | **禁用 + 可发现原因** | 保留可见性＝用户知道"有这个，只是我不能" | `opacity .5` + `cursor not-allowed` + **锁图标** + Tooltip「无编辑数据权限」 |
| **该能力对用户完全不相关**（如 owner 专属的检索管理、非企业环境的 MCP） | **隐藏入口**（不禁用） | 避免噪音 | 直戳 URL 时回落并给出「此功能未在当前环境开放」说明页，**不要静默跳回首页** |
| **整个页面/面板用户无权访问** | **整块替换**为说明卡 | 比隐藏更友好 | 图标 + 「没有访问权限」+ 副文案「联系工作区所有者申请」 |
| **资源类型不支持某动作** | **禁用 + 原因** | 动作存在只是不适用 | Checkbox 禁用 + 灰字「该资源类型不支持此动作」 |
| **删除/降级保护**（owner 行、最后一个 owner、自己） | **禁用 + 原因** | 见 §4.1 | 下拉禁用 + Tooltip「不能修改所有者」 |

### 4.1 必须由前端预判的守卫（现状全部只靠后端报错）

| 守卫 | 前端处理 |
|---|---|
| 不能移除/停用自己 | 按钮**禁用** + Tooltip「不能对自己的账号执行此操作」 |
| 至少保留一位工作区所有者 | 按钮禁用 + Tooltip「至少保留一位工作区所有者，请先移交」+ **可操作跳转**（打开转让面板） |
| 不能修改/移除 owner 行 | 禁用（现状已是） |
| 部门/菜单不能移动到自身或后代 | 目标下拉**排除**自身与后代；若已选则主按钮禁用 + 红字 |
| 至少保留一个视图 / 一个选项卡 / 一个角色 | 只剩一个时删除按钮禁用 + 文案「至少保留一个」 |
| 至少保留一个主部门 | `checked.size===0` 时保存按钮禁用 |
| 注销账号时仍是唯一 owner | 按钮禁用 + 转让引导 |

## 5. 键盘与可达性规范（新增）

### 5.1 Grid 键盘模型

| 键 | 行为 |
|---|---|
| ↑↓←→ | 移动 active 单元格；**移动后必须 `scrollIntoView({block:'nearest'})`** |
| Enter | 进入编辑（**只读字段不进入**）；编辑态＝提交并下移 |
| Tab / Shift+Tab | 编辑态＝提交并右移/左移；非编辑态＝移出表格（保留浏览器默认） |
| Esc | 编辑态＝取消编辑；非编辑态＝清除 active（**不清选择、不关抽屉**） |
| Space | 切换行勾选 |
| Shift + ↑↓ | 连续多选 |
| ⌘/Ctrl + C / V | 复制 / 粘贴选中区域（**现状未实现**，本期最小版：单行多列文本） |
| Delete | 清空选中单元格（可撤销） |
| Home / End | 跳到首列 / 末列 |

### 5.2 虚拟化列表可达性（现状：只有窗口内行在 DOM）

- 列表容器 `role="tree"` / `role="grid"`，行 `role="treeitem"` / `role="row"`。
- 必须提供 `aria-setsize` / `aria-posinset` / `aria-level`，让读屏知道总量与位置。
- **键盘导航时自动把目标行滚入窗口并渲染**（`scrollIntoView` + 更新虚拟窗口），保证 Tab / 方向键可达所有行。
- 导航行高 `NAV_ROW_H=32`、二级 `31`、通讯录 `52` 保持不变。

### 5.3 焦点与浮层

| 项 | 规范 |
|---|---|
| 打开弹窗 | 自动聚焦主输入（无输入则聚焦主按钮） |
| 焦点陷阱 | Tab 循环限制在弹窗内 |
| 关闭后 | **焦点归还触发元素** |
| Esc | 所有弹窗/抽屉/浮层**必须支持**（现状 5 处缺失：FilterRuleModal、FormulaEditorModal、MoveToGroupModal、MemberDrawer、VersionHistoryDrawer、窄屏导航抽屉） |
| Esc 语义 | **有未保存改动时，Esc 必须走"放弃确认"，不得直接关闭** |
| 滚动锁定 | 弹窗打开时锁 body 滚动（现状全仓 0 处），关闭时恢复并保留滚动位置 |
| ARIA | `role="dialog"` + `aria-modal="true"` + `aria-labelledby` 指向标题 |

### 5.4 禁用 hover-only

所有当前 `opacity-0 group-hover:opacity-100` 的行操作（二级导航 ⋮、编排器 ⋯、文档树 ⋯、部门 ⋯），统一改为 **常驻竖向三点 ⋮**，`gx-text-hint`，hover 加深为 `gx-text-2`，`:focus-visible` 显示外环。触屏与键盘均可操作。

> **【例外条款 · 2026-09-18 用户裁决 D-4】** 行内「更多操作 ⋮」改回**默认隐藏、hover 才显示**（形态仍为竖向 ⋮）。此例外成立的前提是必须同时满足四条，缺一即退回常驻：
> ① 隐藏时**保留 20×20 占位**，不得因显隐引起行内重排；
> ② `group-focus-within` / 自身 `:focus-visible` 时显形（键盘可达）；
> ③ `@media (hover: none)` 触屏设备常驻显示；
> ④ 菜单展开态常驻显示。
> 其余 hover-only 操作（非「更多操作」类）仍按本节正文禁用。详见 `10-implementation-rulings.md` §1。

## 6. 表单校验与错误落位规范（新增）

现状：基座 `Input`/`Textarea`/`Select` **没有 error 属性**，业务方四种落位。统一为：

### 6.1 控件补全

| 控件 | 新增状态 |
|---|---|
| Input / Textarea | `error?: string` → 边 `gx-danger` + 下方 `gx-11` `gx-danger` 文案 + `aria-invalid` + `aria-describedby` |
| Select | 同上；focus 加 2px `gx-accent` 外环 |
| IconButton | 补 Disabled（`opacity .4` + `cursor not-allowed`）与 loading |
| Switch | 补 `disabled` 参数 |

### 6.2 落位规则

| 错误类型 | 落位 |
|---|---|
| 字段格式 / 长度 / 必填 | **字段下方** |
| 跨字段逻辑（两次密码不一致、结束早于开始） | 后一个字段下方 |
| 服务端返回且可映射到字段（重名、用户名已存在、邮箱已注册） | **对应字段下方**（现状多为 toast，需补映射） |
| 服务端返回但无法映射 | 表单顶部错误条（`gx-danger-bg`） |
| 操作级失败 | 触发按钮上方一行红条 + 重试 |

### 6.3 校验时机

- **即时校验**：格式类（邮箱、字符集、长度上限在 `maxLength` 已挡的前提下不再提示）。
- **失焦校验**：必填、长度下限。
- **提交校验**：唯一性、跨字段逻辑。
- **禁止**：输入过程中弹 toast。

### 6.4 需要前端预判但现状缺失的校验

| 项 | 现状 | 补齐 |
|---|---|---|
| 邮箱格式 | 三处不一致（有正则 / 无校验 / 只判空） | 统一正则 + 失焦提示 |
| 名称长度 | 部分有 `maxLength` 无提示 | 统一 1–60，超限提示 |
| 重名（字段/分组/视图/文档/知识库/用户名） | 全靠后端 | 能本地比对的一律本地提示（列表已在手：字段、视图、文档树） |
| 数值越界 | 静默钳制 | 钳制后提示「已调整为可选范围 0–8」 |
| 级联清空 | 静默 | **切换前若下游已有值，弹确认**或清空后就近提示「已清空 XX，请重新选择」 |

## 7. 弹窗与浮层规范补全

| 项 | 现状 | 补齐 |
|---|---|---|
| 层级档位 | 只有 drawer/modal/popover/toast 四档 | **新增二级弹窗档 `gx-z-modal-nested = 860`**（高于 modal 800，低于 toast 1000），消灭 `z-[60]` / `z-[820]` 硬编码 |
| 入场动画 | 无 | 180ms 淡入 + scale .96→1；抽屉 200ms 位移 |
| 滚动锁定 | 全仓 0 处 | `body { overflow: hidden }` + 右侧补偿滚动条宽度 |
| 无 title 的弹窗 | 无关闭按钮 | 强制：无 title 时右上角仍渲染 ✕ |
| 取消/关闭按钮 | 三种文案 | 统一「取消」，特殊场景「返回修改」 |
| 抽屉 | 五处自绘 | 收敛为 `Drawer` 组件：右侧，宽 480（记录抽屉保留拖拽 [380,900]），头 48，右上关闭，遮罩 `rgba(0,0,0,.25)`，Esc 可关 |
| 多选浮层截断 | 硬截 200 无提示 | 截断处显示 `ResultNotice` + 「仅显示前 200 条，请缩小搜索范围」 |
| 复制失败 | 三套文案 + 一处静默 | 统一「复制失败，请手动选中复制」+ 输入框 `readOnly` 且 focus 自动全选 |

## 8. 导航与壳层补全

### 8.1 断点（现状 <1024 存在死交互）

| 断点 | 结构 |
|---|---|
| ≥1280 | 顶栏 + L1(224) + L2(240) + 内容区 |
| 1024–1280 | 顶栏 + L1(224) + L2(240) + 内容区（L2 可收起，收起后浮层展示） |
| 768–1024 | 顶栏 + **抽屉式导航**（左滑出，遮罩关闭，**必须支持 Esc 与焦点陷阱**）；点数据库后 L2 以**二级滑层**出现在抽屉内（现状永不渲染＝死交互，必须修） |
| <768 | 同上；表格切换为**卡片聚合视图**（一行记录＝一张卡片），工具栏折叠为「筛选/排序/更多」三个入口 |

### 8.2 状态持久化（现状只有 `gx-auth`）

| 项 | 存储 | 默认值 |
|---|---|---|
| L1 折叠/展开容器集合 | localStorage `gx-nav-collapsed` | 全部展开 |
| L1 是否折叠为 56 档 | localStorage `gx-nav-rail` | false |
| L2 展开/关闭 | localStorage `gx-nav-secondary` | 展开 |
| 二级面板滚动位置 | sessionStorage（按 containerId） | 0 |
| 文档树折叠 / Tab | 现状已有 `gx-kb-collapsed-{kbId}` / `gx-kb-tab-{kbId}`，保留并统一前缀为 `gx-` |

> 配套修复：ErrorBoundary 的 `key` 不应再绑定 `pathname`（否则每次跳转全丢）。改为仅在**错误发生时**用错误签名做 key。

### 8.3 ContextBar（40px 视图标签条）

```
[表格视图] [看板] [日历] [画廊]        ⋮   ⚙   ＋
 └── 选中：gx-surface 白卡 + shadow-sm ──┘
```

- Tab 切换、双击重命名、＋ 新建视图（名称 `maxLength=60`，Enter 提交）。
- `⋮`＝**竖向**三点：编辑视图 / 重命名 / 复制 / 设为默认 / 删除。
- `⚙`＝视图配置抽屉（筛选条件、分组、排序、字段显隐、行高、行颜色、锁定模式）。
- 溢出：横向滚动 + 左右渐隐，**不加箭头**（保持极简）。

### 8.4 二级面板（表列表）

| 元素 | 规格 |
|---|---|
| 头部 | 当前库名 + 类型图标 + **竖向 ⋮**（库级：新建数据表 / 导入建表 / 导出全库 / 分享协作 / 库设置 / 删除库） |
| 搜索 | 过滤**表名**（非记录），无防抖（本地列表），带清空 ✕ |
| 列表 | 表图标 + 表名（12/13）+ **竖向 ⋮ 常驻**：编辑 / 重命名 / 复制 / 移动到 / 导出 / 删除 |
| 底部 | ＋ 新建数据表 |
| 空态 | 「这个数据库还没有数据表 / 新建第一张表开始记录数据。」+ 主操作 |

## 9. 表格与视图补全

### 9.1 单元格与行

| 项 | 规范 |
|---|---|
| 点击命中边界 | **点单元格＝选中；点行首空白区或展开按钮＝开抽屉**。修复现状"点文本同时选中并开抽屉" |
| 选中行 | 左缘 3px `gx-accent` 竖条（现状被行色条占用，需分离：行色条用左侧 3px 内嵌，选中态用外扩竖条） |
| 行号 | `gx-11` `gx-text-hint`，右对齐，可在视图设置里开关 |
| 保存指示 | 单元格右下角：保存中＝脉冲点；成功＝✓ 淡出 1.2s；失败＝红边 + 重试气泡 |
| 只读用户双击 | **不再静默**：显示 Tooltip「你没有编辑该表的权限」 |
| 计算字段 Enter | **不进入编辑**，显示 Tooltip「该字段由公式自动计算」 |
| 附件 | 补四态：超大文件（预校验提示）、超数量、上传中（进度）、失败可重试；**抽屉与表单内也要支持**（现状不支持） |

### 9.2 批量操作

| 项 | 规范 |
|---|---|
| 批量条 | 现状"整条替换"导致筛选/分组不可达 → 改为**追加一行**在原工具栏下方，原工具栏保留但置为次级 |
| 批量删除 | L1 级：执行 + Toast「已删除 N 行 **撤销**」，撤销窗口 8s |
| 批量修改 | 支持多字段；按字段类型给控件；**校验 `canEditData`**；带进度与部分失败报告 |
| 上限 | >500 行时提示「已选 N 行，超过 500 行请分批操作」 |

### 9.3 分页 / 续翻

| 项 | 规范 |
|---|---|
| keyset 关闭 | 显示「仅显示前 200 条，请增加筛选条件」+ 提供服务端全量导出入口（现状"加载更多"永不出现） |
| 触底续翻 | 底部 Spinner + 文案「加载中…」 |
| **已到底** | 显示「已显示全部 N 条」（现状静默） |
| 游标失效 | **必须提示**：Toast「数据已更新，已回到第一页」+ 滚动到顶部（现状静默回第一页） |

### 9.4 视图配置

| 项 | 规范 |
|---|---|
| 写回 | 加 300ms 防抖合并；**失败必须回滚**并显示「保存视图配置失败 重试」 |
| 保存指示 | 头部显示「保存中… / 已保存」（现状无） |
| 锁定模式 | `locked` 时工具栏整体禁用 + 顶部说明条「该视图已被锁定，联系创建者修改」；`personal` 时提示「仅你可见的个性化配置」 |
| CSV 导出 | 统一走**服务端全量**（消灭两条路径），文件名 `{表名}-{YYYYMMDD}.csv`，带 BOM |
| CSV 导入 | 最小向导：选文件 → 列映射 → 预览前 10 行 → 导入 → **行级错误报告可下载** |

## 10. 知识库外壳补全

| 项 | 规范 |
|---|---|
| **文档树交互** | 竖向 ⋮ 常驻（编辑 / 重命名 / 新建子文档 / 移动 / 分享 / 复制链接 / 删除）；支持右键菜单（沿用 `05` §5 的 220 宽规范）；拖拽时显示插入位置指示线；**非法落点**给出行内提示而非只在 toast |
| **树溢出** | 最深 6 层，超出部分折叠为「更多子文档」；超长名称省略 + Tooltip；节点 >300 时启用虚拟化 |
| **保存四态** | dirty（黄点「有未保存更改」）/ saving（转圈「保存中…」）/ saved（✓「已保存」）/ **failed（红点「保存失败 重试」）**——第四态是新增 |
| **草稿恢复条** | 顶栏下方黄条：时间 + 「恢复草稿」「丢弃」+ 关闭 ✕；丢弃需二次确认 |
| **冲突** | 409 时不再只 toast：弹「文档已被他人修改」+ 两个选项「保留我的（覆盖）」「使用服务端版本（我的存入草稿）」 |
| **面包屑** | 补：库名 / 父文档链（最多 3 层，中间折叠为「…」）/ 当前文档名 |
| **顶栏溢出** | ≥1024 全展开；768–1024 收起分享与版本历史进 ⋮；<768 只保留返回 + 标题 + 保存状态 |
| **KB 级入口** | 知识库级 ⋯（重命名 / 移动 / 分享 / 删除）放到 **L2 头部 ⋮**；KB 回收站与设置页入口同样收进该菜单 |
| **大纲受外壳影响** | `topGap` 由硬编码 64 改为读取顶栏实际高度；`right` 由 L2/抽屉宽度决定，**不覆盖内容** |

## 12. 落地优先级

| 批次 | 内容 | 理由 |
|---|---|---|
| **P0 · 先做** | §1 状态与异常态、§2 反馈体系、§3 确认矩阵、§6 表单校验、§7 弹窗焦点与层级 | 这五块是"用户不知道发生了什么 / 数据丢了找不回"的根源 |

| **P2 · 跟进** | §9 表格补全、§10 知识库外壳、§11 新增组件 | 依赖壳层稳定后再铺开 |
| **P3 · 打磨** | 导入导出向导、ERD 重做、评论功能、审计日志 | 需先经 Q-5 / Q-6 / Q-8 决策 |

### 验收口径（每条可勾选）

- [ ] 全仓无 `window.confirm` / `window.alert` / `window.prompt`
- [ ] 全仓无 hover-only 的必备操作（可 grep `group-hover:opacity-100` 逐项确认）
- [ ] 全仓无原生 `title` 承担解释职责
- [ ] 所有虚拟化列表有 `role` / `aria-setsize` / `aria-posinset`，键盘可达全部行
- [ ] 所有弹窗有 Esc / 焦点陷阱 / 焦点归还 / 滚动锁定

- [ ] 所有不可逆操作落在 L1–L5 矩阵的某一级，且有对应确认形态
- [ ] 所有表单错误落在字段下方或就近错误条，且无英文前缀
- [ ] 所有列表有空态、加载态、错误态、到底态四种呈现
- [ ] 全仓只有一套 EmptyState / Drawer / ColorPicker / ConfirmDialog
