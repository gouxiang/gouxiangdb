## 知识库

知识库用来沉淀文档（富文本）与画布（自由白板）。它和「数据库」平级，都在第一列里。

**入口**：第一列点击任一知识库名 → 第二列顶部出现「文档 / 画布」两个选项卡，下面是该库的全部内容。

![第一列选中知识库后，第二列显示「文档 / 画布」选项卡与内容列表](assets/kb-l1-selected.png)

---

### 打开知识库

**入口**：第一列 → 点击知识库名。

**步骤**：
1. 在第一列找到目标知识库（书本图标）。
2. 点击后展开第二列。
3. 点「文档」或「画布」选项卡切换要浏览的内容类型。
4. 在第二列点击某一条内容，右侧打开它。

**说明**：第一列很长时用鼠标滚轮滚动即可；窗口宽度小于 768 像素时第一列收进左上角抽屉，需要先点抽屉按钮。

---

### 新建知识库

**入口**：第一列顶部 → 「新建知识库」。

![第一列顶部的新建数据库 / 新建知识库两个按钮](assets/nav-create-kb.png)

**步骤**：
1. 点击第一列顶部的「新建知识库」。
2. 在弹窗里填写知识库名称。
3. 点击创建。
4. 创建完成后自动进入新库，可以直接开始建文档。

**说明**：图标与颜色由系统按名称自动生成，之后可以改。「新建数据库」按钮就在它上方，两个按钮互相独立，别点错。

---

### 重命名知识库 / 改图标与颜色

**入口**：工作区设置 → 资产 → 「知识库」分组里点目标库 → 知识库设置页 → 「基本信息」区。

![知识库设置页基本信息与成员管理区](assets/kb-settings-basic.png)

**步骤**：
1. 点击第一列底部的「工作区设置」（齿轮图标）。
2. 切到「资产」分区。
3. 在「知识库」分组里点击要改的库，进入知识库设置页。
4. 在「基本信息」里改名称输入框中的文字，点击保存。
5. 需要改图标或颜色时，点击名称左侧的图标，选完立即生效，不用保存。

**说明**：只有知识库的**所有者**能改（源码 `apps/web/src/features/kb/KbSettingsPage.tsx:122` 处名称输入框带 `readOnly={!isOwner}`）。非所有者看到的是只读文字，图标也不可点。

**注意**：这是当前版本唯一可达的知识库设置入口。旧版本从知识库左侧栏进「设置」的位置已经不存在了，不要再按那个路径找。

---

### 知识库成员与角色

**入口**：工作区设置 → 资产 → 目标库 → 知识库设置页 → 「知识库成员」区与「添加成员」区。

![知识库设置页成员列表与添加成员区](assets/kb-settings-members.png)

**步骤**：
1. 按上一节的路径进入知识库设置页。
2. 在「添加成员」里输入对方**已注册的邮箱**，选择角色（可编辑 / 可评论 / 仅查看），点击添加。
3. 成员出现在「知识库成员」列表中，可直接改角色或移除。

**说明**：
- 这里是**知识库级**的成员角色，对库内全部文档与画布生效，三档：可编辑、可评论、仅查看。
- 组织层面的部门、成员、组织角色不在这里，在「工作区设置 → 通讯录」。两层互相独立。
- 要邀请**还没注册**的人，应该去「通讯录 → 添加」，而不是在这里按邮箱添加——这里只能加已注册账号。

**注意**：移除成员没有撤销按钮，弹窗会要求你确认一次。被移除的人可以重新加回来。

---

### 知识库回收站

**入口**：两种方式
- 第二列列表最底部的「回收站」行。
- 工作区设置 → 回收站 → 「知识库回收站」分组里点目标库。

![知识库回收站列表，每项可找回或彻底删除](assets/kb-trash.png)

**步骤**：
1. 在第一列选中目标知识库。
2. 点击第二列最底部的「回收站」。
3. 列表里每项右侧有「找回」与「彻底删除」两个按钮。
4. 点「找回」恢复；点「彻底删除」需要在弹窗里再确认一次（按钮文案是具体动词，不是「确定」）。

**说明**：删除的文档与画布会保留在回收站，30 天内可找回。彻底删除会连同它的全部历史版本与授权一起删除，不可恢复。

---

### 上传限制（本机生效）

**入口**：工作区设置 → 通用 → 页面下方的「上传限制」卡片。

**步骤**：
1. 打开「工作区设置 → 通用」。
2. 滚到页面下方的上传限制卡片。
3. 为图片 / 视频 / 音频 / PDF / 附件五类分别设置单个文件大小上限（MB）与允许的扩展名。
4. 改动即时生效，不用点保存。

**说明**：这套限制**只对你当前这台浏览器生效**，保存在本机，也不会跟着账号同步到别人的电脑。它只对文档编辑器里的上传行为生效（插入图片、视频、音频、PDF、附件），不影响数据库里的附件字段。

**注意**：这个卡片原来挂在知识库设置页里，后来上提到工作区层级（源码 `apps/web/src/features/workspace/WorkspaceSettingsPage.tsx:29` 注释）。现在知识库设置页里只留了一句「已移到工作区设置」的说明，不能再在那里改。

---

### 知识库的边界与已知限制

- **没有「删除知识库」的操作**。删除接口在代码里是有的（`apps/web/src/features/kb/kb-hooks.ts:52` 的 `useDeleteKb`），但当前界面上没有任何地方调用它，知识库设置页也没有删除区。需要删库请联系管理员从后台处理。
- 知识库**不能改名之外的高级设置**：没有封面、没有模板、没有导出整库的功能。
- 知识库之间**不能移动**文档与画布，只能在同一个库里调整层级。
- 回收站是**库级**的：删了某个库的东西，要到那个库里去翻回收站，其他地方找不到。

---

## 文档与画布（内容条目）

一个知识库里可以放两种内容：**文档**（富文本）和**画布**（白板）。这一章讲它们共同的增删改操作。

### 新建文档 / 新建画布

**入口**：第二列 → 先点「文档」或「画布」选项卡 → 选项卡行右侧的「新建文档」/「新建画布」按钮。

![第二列顶部「文档 / 画布」选项卡与右侧新建按钮](assets/l2-kb-tabs.png)

**步骤**：
1. 在第一列选中目标知识库，展开第二列。
2. 点「文档」选项卡 → 右侧出现「新建文档」；点「画布」选项卡 → 右侧出现「新建画布」。
3. 点击该按钮，立即创建并跳转进入新内容。
4. 新内容默认标题是「未命名文档」/「未命名画布」，在页面顶栏改。

**说明**：需要知识库角色为**所有者**或**可编辑**。如果是「可评论」或「仅查看」，这个按钮不会出现（系统在不给权限时是直接隐藏入口，而不是把按钮置灰）。

**注意**：这个按钮只按当前选项卡决定建哪种内容——想建画布就先切到「画布」选项卡，别在「文档」选项卡里找建画布的入口。

---

### 打开文档 / 打开画布

**入口**：第二列 → 切换选项卡 → 点击某一条内容。也可以按 Command + K（Windows / Linux 为 Ctrl + K）用全局搜索打开。

**步骤**：
1. 选中知识库后在第二列切换「文档」/「画布」选项卡。
2. 点击列表里的标题打开。
3. 页面右上角可能出现的三个状态字（保存中 / 已保存到云端 / 有未保存更改）用来判断内容是否已经安全落地。

---

### 重命名、改图标与颜色

**入口**：两种方式
- 在编辑器顶栏直接改标题输入框（失焦或回车即保存）。
- 在知识库首页列表里，鼠标悬停某一行 → 行尾三点菜单 → 「重命名」/「图标与颜色」。

**步骤（列表方式）**：
1. 第二列点第二条以前的方式进入知识库首页（在编辑器里点左上角返回箭头，或直接在第一列重新点该库）。
2. 鼠标移到目标行，点击行尾的三点图标。
3. 点「重命名」改标题，或点「图标与颜色」改外观。
4. 图标与颜色是选完立即生效的，不走「保存」。

**说明**：知识库首页的地址是 `/kb/<知识库id>`，里面同时列出文档与画布，并带类型筛选与搜索框。

---

### 调整文档树层级（拖拽）

**入口**：第二列 → 「文档」选项卡 → 按住某一行拖动。

**步骤**：
1. 切到「文档」选项卡。
2. 按住某个文档行往上或往下拖。
3. 拖到另一个文档行上松手 → 它成为那条文档的子级。
4. 拖到列表顶部的「拖到此处移到顶级」区域松手 → 它回到顶级。

**说明**：
- 拖拽只对**文档**生效，画布行不能拖（源码 `apps/web/src/features/workspace/SecondaryNavKbOps.tsx:10` 明确指出画布不参与拖拽）。
- 不能把一个文档拖到它自己或它自己的子级里，遇到这种情况会提示「无法移动：不能将文档放到它自己或它的子级中」。
- 需要「所有者 / 可编辑」角色。

---

### 删除文档或画布并找回

**入口**：知识库首页列表 → 行尾三点菜单 → 「删除」。

**步骤**：
1. 进入知识库首页。
2. 鼠标悬停目标行，点行尾三点图标。
3. 点击红色的「删除」。
4. 在弹窗里点「删除并移入回收站」确认。
5. 误删时立刻点右下角提示条上的「撤销」（约 6 秒内有效）；错过就到回收站找回。

**说明**：删除是软删除，先进回收站，30 天内可找回，不是立刻消失。

---

### 给单篇文档或画布设「独立权限」

**入口**：知识库首页列表 → 行尾三点菜单 → 「独立权限」。

**步骤**：
1. 进入知识库首页。
2. 鼠标悬停目标行，点行尾三点图标。
3. 点击「独立权限」，弹出授权窗口。
4. 按邮箱选择成员（可编辑 / 可评论 / 仅查看），设置即写入。
5. 已在列表中的授权可以改档或撤销。

**说明**：独立权限与「知识库成员角色」**叠加**，两者取更高的那个。也就是说：库级已经给了「可编辑」，再用独立权限把它降成「仅查看」是无效的。

**注意**：当组织级的权限引擎开启时，这个窗口会换成资源树授权视图，可以按部门 / 角色授予；默认安装下是三档邮箱视图。详见「权限」一章。

---

### 文档与画布的边界与已知限制

- 内容只能在**同一个知识库内**移动，不能跨库。
- 画布不能成为父级，文档树只由文档构成层级。
- 单个内容没有「复制一份」的入口，需要复制请新建后手动粘贴内容。
- 独立权限的最小粒度是**单篇文档或单个画布**，没有更细的「段落级 / 区块级」权限。

## 文档编辑器

文档编辑器同时照顾两类人：习惯写字的人用所见即所得（富文本），习惯 Markdown 的人可以直接写源码并预览。

![文档编辑器顶栏、保存/分享/版本历史按钮与右侧悬浮目录](assets/doc-editor-topbar.png)

---

### 编辑器顶栏有什么

打开一篇文档后，页面最上面一行从左到右依次是：

| 位置 | 作用 |
| --- | --- |
| 返回箭头 | 回到知识库首页 |
| 标题输入框 | 改这一篇的标题，失焦或按回车保存 |
| 保存状态文字 | 保存中 / 已保存到云端 / 有未保存更改 |
| 「保存」按钮 | 立即保存到云端（快捷键 Command + S） |
| 「分享」按钮 | 打开分享窗口 |
| 「版本历史」按钮 | 打开版本历史抽屉 |

**说明**：如果这篇文档你只有只读权限，标题输入框会被锁住、「保存」按钮不显示，编辑器自动以「预览」模式打开。

---

### 三种模式：编辑 / 源码 / 预览

**入口**：编辑器内容区左上角的模式切换（编辑 / 源码 / 预览）。

![文档编辑器左上角的编辑 / 源码 / 预览切换条](assets/doc-mode-switch.png)

**步骤**：
1. 打开一篇文档。
2. 点「编辑」进入所见即所得模式（默认）。
3. 点「源码」切成 Markdown 源码模式，可以直接书写语法。
4. 点「预览」看最终渲染效果，此模式只读。

**说明**：三种模式共享同一份内容，切换不会丢字。**只读权限的人看不到这三档切换**，直接停在预览态。

**注意**：预览模式下嵌在文档里的画布会变成可交互预览（可以滚动缩放，但不能改），这样排版效果与最终呈现一致。

---

### 自动保存、手动保存与本地草稿

**入口**：无需入口，系统自动处理；需要立刻落盘时点顶栏「保存」或按 Command + S。

**步骤**：
1. 正常打字，不用管保存——修改会防抖后自动存到云端，同时在本机留一份草稿。
2. 想立刻保存，按 Command + S 或点「保存」。
3. 下次打开这篇文档时，如果检测到上次有没存上去的草稿，页面顶部会出现提示条。
4. 点「恢复草稿」用它覆盖当前内容，或点「丢弃」不要它。

![检测到未保存本地草稿时的顶部恢复提示条](assets/doc-draft-recover.png)

**说明**：保存状态三个的含义——「保存中」正在上传、「已保存到云端」已落库、「有未保存更改」还在等待防抖或网络受阻。

**注意**：本地草稿存在浏览器里。**清理浏览器数据或换一台电脑，草稿就找不回来了**，只有已经「已保存到云端」的内容是安全的。

---

### 保存冲突（两个人同时改）

如果保存时发现服务端的内容比你手上的更新，页面顶部会出现一条橙色提示条。

![保存冲突提示条：查看最新版本与保留我的版本](assets/doc-conflict-notice.png)

**步骤**：
1. 看到冲突提示条时先别继续打字。
2. 点「查看最新版本」：放弃你本地没保存的内容，加载别人保存的版本。
3. 点「保留我的版本」：用你的内容覆盖服务端。
4. 选择后继续编辑并保存。

**说明**：系统**不会**静默覆盖任何一方。选择前建议先确认对方改了什么，避免白做。

---

### 区块操作：换行、拆分、上下移动

文档是由一个个「块」组成的（段落、标题、列表项……都是块）。

**操作方式**：

| 想做的事 | 怎么做 |
| --- | --- |
| 在块末尾回车，新建一个同级块 | 直接按回车 |
| 在一个块的中间拆成两个块 | 把光标放在要拆的位置，按回车 |
| 让新块继承上一个块的类型（例如在列表项末尾回车继续列列表） | 直接按回车，会自动继承 |
| 把当前块整体上移 / 下移 | 按 Alt + ↑ / Alt + ↓ |
| 循环切换当前块的类型 | 按 Command + Option + N（Windows / Linux 为 Ctrl + Alt + N） |

**说明**：表格、代码块、分割线这类「不可输入文字的块」之间也留了专门的插入热区——把鼠标移到两块之间的缝隙，会出现一条可点击的插入位置提示，点它就能在两块中间新起一段。

---

### 插入内容（斜杠菜单）

**入口**：在行首或空格后输入 `/`。

![在文档中输入 `/` 后弹出的斜杠插入菜单](assets/doc-slash-menu.png)

**步骤**：
1. 把光标放在一个空行（或一行的行首）。
2. 输入 `/`，立即弹出插入菜单。
3. 继续输入关键字过滤，例如 `/表格`、`/代码`、`/图片`。
4. 用 ↑ ↓ 选择，按回车或 Tab 插入；按 Esc 取消。

**菜单里全部可以插入的东西**：

| 分类 | 可插入的条目 |
| --- | --- |
| 转成某种块 | 正文、标题 1–4、无序列表、有序列表、待办清单、引用 |
| 插入块 | 代码块、表格（3×3）、数学公式、分割线、分页符、折叠块、提示块 |
| 插入素材 | 图片、视频、音频、PDF、附件 |
| 插入链接 | 链接到文档/画布、链接到数据表 |
| 行内包裹 | 加粗、斜体、删除线、高亮、行内代码、链接 |

**说明**：斜杠菜单的所有条目定义都在 `apps/web/src/features/kb/WysiwygEditor.tsx:100` 起的 `CMDS` 表里，上表与之一一对应。

**注意**：`/` 必须打在**行首或空格之后**才触发菜单，在一段文字中间打 `/` 只是普通字符。

---

### Markdown 行首快捷输入

不用斜杠菜单也能排版：在一个新行的行首输入下列记号再加一个空格，会自动变成对应块。

| 输入 | 变成 |
| --- | --- |
| `# ` | 一级标题 |
| `## ` | 二级标题 |
| `### ` | 三级标题 |
| `#### ` | 四级标题 |
| `- ` 或 `* ` 或 `+ ` | 无序列表项 |
| `1. ` | 有序列表项 |
| `[ ] ` | 待办清单项 |
| `> ` | 引用块 |

---

### 行内格式快捷键

| 快捷键 | 效果 |
| --- | --- |
| Command / Ctrl + B | 加粗 |
| Command / Ctrl + I | 斜体 |
| Command / Ctrl + Shift + X | 删除线 |
| Command / Ctrl + E | 行内代码 |

**说明**：工具条上另有加粗、斜体、删除线、高亮、行内代码、链接六个按钮，以及「上传图片」「上传附件」两个按钮，与快捷键等价，记不住快捷键就点按钮。

**注意**：使用中文输入法时，输入法组字过程中的按键不会被当成快捷键，组字结束后按才生效——这是刻意的防误触设计。

---

### 提及成员与引用文档 / 画布

**入口**：在文档里输入 `@`。

![文档中输入 `@` 后弹出的成员与文档/画布选择面板](assets/doc-mention-picker.png)

**步骤**：
1. 在一行的行首或空格之后输入 `@`，弹出选择面板。
2. 继续输入关键字过滤，面板分「成员」与「文档和画布」两组。
3. 选中成员 = 提及他；选中文档 / 画布 = 插入指向它的链接。
4. 如果想把某个画布**直接嵌进文档里显示**，把鼠标移到那一条上，点右侧出现的「内嵌」图标。
5. 用 ↑ ↓ 移动、回车选中、Esc 关闭。

**说明**：`@` 必须打在行首或空格之后才触发面板（源码 `apps/web/src/features/kb/WysiwygEditor.tsx:415` 的提示逻辑）。如果紧贴文字后面打 `@`，会弹一次「@ 引用需在行首或空格后输入」的提示。

**注意**：引用列表里不会出现当前这篇文档自己，避免自引用。

---

### 上传图片 / 视频 / 音频 / PDF / 附件

**入口**：斜杠菜单里的对应条目，或工具条上的「上传图片」「上传附件」按钮。

**步骤**：
1. 把光标放在要插入的位置。
2. 输入 `/图片`（或点工具条上的图片按钮），选择本地文件。
3. 上传过程中工具条右侧显示「上传中…」，完成后内容出现在光标位置。
4. 视频、音频、PDF 会变成可直接播放 / 预览的内嵌块，普通附件变成下载卡片。

**说明**：单个文件大小与允许的扩展名受「工作区设置 → 通用 → 上传限制」约束，超出会直接被拒绝。

**注意**：上传的图片是存在服务端里的，不是本机路径，换电脑照样能看。

---

### 文档目录

**入口**：文档右侧自动出现的悬浮目录条，无需开启。

**步骤**：
1. 打开一篇文档。
2. 右侧中部的浮动面板就是目录，按正文里的一级到三级标题自动生成，带缩进层级。
3. 点击目录里任意一条，正文平滑滚动到那个标题。
4. 滚动正文时，目录会自动高亮当前所在小节。

**说明**：目录只在正文里**至少有一个标题**时才出现；全是没有标题的段落时不显示。目录在编辑态、预览态、以及别人通过分享链接打开时也都在。

---

### 撤销与重做

| 快捷键 | 作用 |
| --- | --- |
| Command / Ctrl + Z | 撤销上一步 |
| Command / Ctrl + Shift + Z | 重做 |
| Command / Ctrl + Y | 重做（等价上面那个） |

**说明**：一次会话内最多保留 100 步撤销，超出后最早的记录会被丢掉。撤销栈不跨文档——切换到另一篇文档就换了一套。

---

### 文档编辑器的边界与已知限制

- **没有「实时多人光标」**：两个人同时编辑同一篇会遇到保存冲突，靠冲突提示条解决。
- 没有评论功能：文档里不能对某一段写评论，只能在别处沟通。
- 表格只能插入 3×3 起步，且**不能在文档编辑器里合并单元格**。
- 上传限制是**本机浏览器级**的，换一台电脑要用同一套限制得重新配一次。

## 版本历史

文档与画布都支持版本历史：给重要节点存一个命名快照，需要时可以回到那一刻。

### 打开版本历史

**入口**：编辑器顶栏 → 「版本历史」按钮。

![文档版本历史抽屉：左侧版本列表与右侧预览区](assets/version-history-drawer.png)

**步骤**：
1. 打开目标文档或画布。
2. 点击顶栏的「版本历史」。
3. 右侧滑出抽屉，左边是版本列表，右边是选中版本的预览。

---

### 存一个命名版本

**入口**：版本历史抽屉左上角 → 输入版本名 → 保存。

**步骤**：
1. 打开版本历史抽屉。
2. 在左上角输入框里填一个有辨识度的名字，例如「评审前版本」。
3. 点击「保存当前版本」。
4. 出现提示「已保存当前版本」，新版本出现在左侧列表里。

**说明**：只有可编辑的人能看到这个输入框；只读成员只能看不能存。

**注意**：系统不会自动给每次编辑都留版本，**需要保留的点请自己存一个**，否则只能碰运气从历史里翻。

---

### 比较与回滚

**入口**：版本历史抽屉 → 左侧点击某个版本 → 右侧预览 → 「回滚到此版本」。

**步骤**：
1. 在左侧列表里点击想看的版本，右侧渲染出那一版内容。
2. 文档版本可以用预览区工具条上的「缩小 / 百分比 / 放大 / 适配视图」调整显示比例；画布版本同理，还能滚动缩放。
3. 确认是想要的版本后，点击「回滚到此版本」。
4. 在确认弹窗里确认，页面自动加载回滚后的内容。

**说明**：回滚前系统会把「当前状态」自动存成一个新版本再覆盖，所以**回滚本身也是可退回的**——想反悔就再回滚到刚才那个新版本。

---

### 版本历史的边界与已知限制

- 版本历史里的旧版本**只能查看不能单独下载**。
- 回滚操作要求可编辑权限，只读成员看不到回滚按钮。
- 这里的版本数量没有在界面上限制，长时间频繁存版本会一直积累。

## 公开分享

一篇文档或一张画布可以通过链接分享给库外的人，对方**不需要登录**。

![分享弹窗：内部成员区与外部链接区](assets/share-modal.png)

---

### 给外部人员发链接

**入口**：编辑器顶栏 → 「分享」按钮 → 弹窗下半部分「外部链接」。

**步骤**：
1. 打开要分享的文档或画布，点顶栏「分享」。
2. 在「外部链接」那一行把开关打开。
3. 打开后下面出现链接输入框，点「复制」把链接发给对方。
4. 在「持链者权限」里选「仅可见」或「可编辑」。

**说明**：
- **仅可见**：拿到链接的人只能看，不能改。
- **可编辑**：拿到链接的人不用登录就能改内容。
- 开关关掉后，之前发出去的链接**立即失效**。

---

### 同步分享下级文档

**入口**：分享弹窗 → 外部链接打开后 → 勾选「同步分享下级文档」。

**步骤**：
1. 打开外部链接开关。
2. 勾选「同步分享下级文档」。
3. 对方打开链接时，页面左侧会出现一篇文档树，可以在被分享的子树里自由切换。

**说明**：这个选项只有**文档**有（源码 `apps/web/src/features/kb/ShareModal.tsx:173` 处按 `kind === "doc"` 条件渲染），画布分享没有这一项。

---

### 调整内部成员的权限

**入口**：分享弹窗 → 上半部分「内部成员」。

**步骤**：
1. 打开分享弹窗。
2. 在「内部成员」区选择「仅可见」或「可编辑」。
3. 设置立即生效。

**说明**：这里的「内部成员」指**这个知识库的团队成员**，共几人在标题上能看到。此处的设置**不会降低**成员已有的权限——如果某人通过知识库成员角色已经是「可编辑」，把它设成「仅可见」不会真的把他降下来。这是另一个知识库设置页的职责。

**注意**：调整内部成员权限需要知识库所有者身份，否则选项是点不动的。

---

### 别人打开链接看到什么

- 文档：居中正文，右侧带目录，左侧可能有文档树（开了同步分享下级时）。
- 画布：整张画布，右上角显示「可编辑」或「仅可见」徽标。
- 链接失效、分享被关闭或忘形取消时，页面显示「分享链接已失效或被取消」。

![匿名用户通过分享链接打开的文档页面](assets/public-share-page.png)

---

### 公开分享的边界与已知限制

- 分享链接**不能设置密码，也不能设置有效期**。要作废只能手动关掉开关。
- 没有「访问次数 / 访问记录」的查看入口。
- 「可编辑」的持链者是**匿名身份**，出了问题无法从界面上追到具体是谁。
- 通过分享链接打开的画布**不能新建关联**（源码 `apps/web/src/features/kb/canvas/CanvasLinkEntry.tsx:36` 明确公开页不渲染入口）。

---

## 画布

画布是一块可以自由摆放内容的白板，支持图形、连线、文字、图片、思维导图，还能把知识库里的文档直接挂到图形上。

![画布编辑页全貌：关联按钮、顶部工具条、缩放条与画布区](assets/canvas-editor-full.png)

---

### 打开与保存画布

**入口**：第二列 → 「画布」选项卡 → 点击某张画布。

**说明**：画布顶栏与文档几乎一样（标题输入框、保存状态、保存、分享、版本历史），快捷键 Command + S 立即保存，自动保存与草稿恢复的行为也完全相同。画布没有自动标题，新画布默认叫「未命名画布」，记得改。

---

### 工具条：可以画些什么

**入口**：画布**顶部居中**那一排工具按钮。

| 工具 | 快捷键 | 用途 |
| --- | --- | --- |
| 选择 | V | 默认工具，点选与框选元素 |
| 手形工具 | H | 拖动整个画布可视区域 |
| 思维导图 | M | 生成可展开分支的脑图节点 |
| 文本 | T | 插入一段纯文字 |
| 箭头 | A | 画带箭头的连线（直线 / 肘线 / 曲线三种呈现） |
| 形状 | — | 长方形 R、圆 O、三角形、椭圆角矩形、菱形、平行四边形、圆角矩形 |
| 图片 | Command + U | 插入本机图片 |
| 画笔 | P | 手绘笔迹 |
| 橡皮擦 | E | 擦除元素 |
| 更多工具 | — | 扩展工具入口 |

**步骤**：
1. 在顶部中间的工具条上点一个工具（或按它的快捷键）。
2. 在画布上按住拖动，画出对应形状；文本 / 图片则是点一下再输入或选文件。
3. 画完后按 V 回到选择工具，再进行调整。

**说明**：双击图形可以在里面写文字；双击已写好的文字可以继续编辑。

---

### 选中、框选与多选

**步骤**：
1. 确认当前工具是「选择」（按 V）。
2. 单击一个元素选中它。
3. 按住鼠标拖动出一个框，框住的元素一起选中。
4. 多选后顶部出现的样式条是对**整组**生效的。

---

### 移动、缩放与平移

| 想做的事 | 怎么做 |
| --- | --- |
| 移动单个或多个元素 | 用「选择」工具选中后直接拖 |
| 平移画布可视区 | 选「手形工具」后拖动；触控板双指平移也可以 |
| 缩放画布 | 鼠标滚轮，或触控板捏合；也可以用**右上角缩放条**上的「缩小 / 百分比 / 放大 / 自适应」 |
| 缩放到 100% | 点击右上角缩放条中间的百分比数字 |
| 一次看到整张画 | 点击右上角缩放条的「自适应」按钮 |

**说明**：缩放范围在 10% 到 500% 之间，到边界后按钮自动置灰。缩放和平移只改视图，不改数据，也不会被撤销栈记录。

**注意**：在只读预览或分享链接里，依然可以滚轮缩放和平移，但不能拖元素、不能改字。

---

### 图层顺序（谁在前面）

**入口**：两种方式
- 在元素上**右键** → 图层菜单四项。
- 快捷键。

| 操作 | 快捷键 |
| --- | --- |
| 上移一层 | Command / Ctrl + ] |
| 下移一层 | Command / Ctrl + [ |
| 置于顶层 | Option + Command / Ctrl + ] |
| 置于底层 | Option + Command / Ctrl + [ |

**步骤**：
1. 选中一个或多个元素。
2. 右键 → 选「上移一层 / 下移一层 / 置于顶层 / 置于底层」，或直接按快捷键。
3. 操作完成后会提示结果；已经在最顶层还往上移时会提示「已在最顶层」。

**说明**：图层调整走的是画布自身的重排，可以撤销，也会随内容自动保存。

**注意**：必须先有选中的元素；在空白处右键不会弹出一个全是置灰项的菜单。

---

### 选中节点后的样式条

选中元素后，它上方会浮出一条工具条，能改的东西按元素类型不同而不同。

![画布上选中图形后上方出现的浮动样式条](assets/canvas-style-bar.png)

| 元素类型 | 可以改什么 |
| --- | --- |
| 图形 | 描边颜色、填充颜色、线条粗细、线型（实线 / 虚线 / 点线）、加粗、斜体、下划线、文字对齐、文字颜色、插入图片、注释、关联文档、图层 |
| 连线 | 线条颜色、粗细、线型、呈现方式（直线 / 曲线 / 折线）、起点样式、终点样式、图层 |
| 思维导图节点 | 节点填充、描边颜色 / 粗细 / 线型、节点形状、文字颜色、分支线颜色 / 粗细 / 形态、布局方向，以及 emoji 与折叠 |
| 图片、文字 | 基础样式与图层 |

**说明**：多个不同类型的元素同时选中时，样式条只显示它们共有的项。

---

### 给元素加注释、关联文档

**入口**：选中元素 → 样式条上的「注释」图标 / 「关联」图标。

**步骤（关联）**：
1. 选中一个图形、连线或脑图节点。
2. 点样式条上的「关联文档或画布」图标。
3. 在弹出的选择器里挑一篇本知识库的文档或画布，也可以当场新建一篇。
4. 关联成功后，元素角上出现一个角标；点击角标展开预览卡，卡里能滚动查看全文、调整卡片大小、直接编辑、点开跳转，或取消关联。

**说明**：注释是挂在元素上的说明文字，同样以角标形式显示。**只读成员和通过链接进来的人也能看到注释与关联角标**，只是不能改。

---

### 用左上角「关联」插入关联块

**入口**：画布左上角 → 「关联」按钮（书本 + 链接图标，仅编辑态可见）。

**步骤**：
1. 点击左上角「关联」。
2. 在弹出的面板里选择一篇文档或画布（可搜索，也可当场新建）。
3. 选中后画布上立即出现一个关联块，并弹出编辑框让你填标题与正文。
4. 填完后关联块就是一个可以随意拖动的卡片，卡片里直接显示关联内容的预览。

**说明**：关联块有「完整预览」（带摘要和图片）和「极简」（只有标题和跳转）两种密度，可以在卡片上切换。

---

### 在文档里嵌入画布、在画布里跳到文档

**步骤（在文档里嵌一张画布）**：
1. 打开目标文档，把光标放在要插入的位置。
2. 输入 `@`，在面板里切到「文档和画布」分组。
3. 找到目标画布那一行，鼠标悬停后点右侧的「内嵌」图标。
4. 画布以预览卡形式出现在文档里（可滚动缩放，不能改）。

![文档中嵌入的画布预览卡](assets/canvas-embed-in-doc.png)

**步骤（在画布里跳到那篇文档）**：
1. 点开某个关联角标或关联块。
2. 点卡片上的跳转入口，直接打开那篇文档 / 画布。

**说明**：文档里嵌画布、画布里嵌文档可以互相套，但系统内置了层数与成环保护——套得太深或自己套自己时，会降级显示成一个占位卡片而不是无限展开或卡死。

---

### 画布的边界与已知限制

- **没有专门的全屏按钮**。画布编辑页顶栏只有返回、标题、保存、分享、版本历史五项，如果想更沉浸，只能用浏览器的全屏功能。
- **关联只能指向知识库里的文档或画布，不能指向数据库里的某条记录**（源码 `apps/web/src/features/kb/canvas/types.ts:15` 定义关联目标只有 `doc` 与 `canvas` 两种）。
- 画布**不能导出为图片或文件**：程序界面上已经把自建的导出菜单隐藏掉了，保存一律走云端。
- 撤销 / 重做是画布引擎自带的能力，界面上没有专门的按钮（用 Command / Ctrl + Z）。
- 通过公开链接打开画布时，左上角没有「关联」按钮。

## 账号与个人设置

### 注册与登录

**入口**：系统首页（未登录时自动跳 `/login`）。

**步骤（有新账号需要开）**：
1. 打开登录页。
2. 点右上角的「注册」档，切到右 tab。
3. 填写昵称、邮箱、密码（**至少 8 位**）、确认密码。
4. 点「创建并登录」。

**步骤（已有账号）**：
1. 在登录档输入邮箱与密码。
2. 点「登录」。

**说明**：
- 如果这是整个工作区的**第一个账号**，登录页会直接显示「初始化工作台 · 创建超级管理员」，这个账号自动成为超级管理员，拥有全部权限。
- 「注册」这一档是否出现取决于管理员是否开启了自助注册。没有这一档时，只能让管理员在通讯录里邀请你。
- 会话过期时会自动跳到登录页并给出说明横幅，登录后回到原来那一页。

## 通讯录

通讯录负责组织层面的部门、成员与组织角色。它与各库自己的成员页面是**两层独立的切面**。

**入口**：两种方式
- 第一列底部 → 「通讯录」。
- 工作区设置 → 通讯录（同一套界面）。

**说明**：窗口宽度 1024 像素以上时同时显示三栏（部门树 / 成员 / 角色）；窄于 1024 时退化成两个下标切换。

![通讯录三栏：左侧部门树、中间成员列表、右侧角色管理](assets/contacts-three-columns.png)

---

### 管理部门

**入口**：左侧部门树。

**步骤（新建）**：
1. 在部门树下方点「新建顶级部门」，输入部门名。
2. 需要在某部门下建子部门时：鼠标移到该部门行 → 点行尾三点菜单 → 「新建子部门」。

**步骤（改名 / 移动 / 删除）**：
1. 鼠标移到目标部门行，点行尾三点图标。
2. 点「重命名」改名。
3. 点「移动」把它挂到另一个父部门下。
4. 点「删除部门」删除（需再次确认）。

**说明**：把部门拖成环（比如把父部门拖到它自己的子部门下面）是不允许的，界面会拦下来。

**注意**：删除部门**不可撤销**。如果部门下还有子部门或成员，删除会失败并提示你先移动或移除，请按提示先处理完再删。

### 管理成员

**入口**：中间成员列表上方的「添加」按钮。

**步骤（添加 / 邀请）**：
1. 点「添加」，弹出邀请窗口。
2. 填写对方邮箱与角色。
3. 确认后生成邀请链接，把链接发给对方；对方用它接受邀请、设置密码后即可加入。
4. 已在列表里的成员，点开可以编辑详情。

**步骤（查找）**：
1. 在搜索框里输入姓名或邮箱关键字（输入后自动延迟 300 毫秒搜索）。
2. 点击左侧部门树中的某个部门，只显示这个部门的人。
3. 清掉筛选后列表复原。

**说明**：列表是**滚动续拉**的，往下滚会自动加载下一页，不需要翻页。

---

### 单个成员可以做什么（成员抽屉）

**入口**：在成员列表里点某个人，右侧滑出抽屉。

**说明**：这里分三块
- **部门归属**：一个人可以属于多个部门，但**有且只有一个主部门**，其余为「兼岗」。勾选 / 取消勾选后点「保存部门」。
- **有效组织角色**：只读显示这个人当前拥有的组织角色，以及每个角色是「直接授予本人」还是「经某个部门继承」来的。
- **停用 / 重新激活**：停用时其**当前登录状态立即失效**，下次任何操作会被退出；部门归属与角色授予会保留，可随时重新激活。

**注意**：待激活账号（已邀请但未设置密码）没有停用按钮，因为还没激活无需停用。

---

### 角色管理

**入口**：通讯录右侧 → 角色列表。

**说明**：角色分两类
- **系统角色**（带皇冠与锁图标）：系统内置，**不可改不可删**，只能看它的说明。五个：工作区所有者、管理员、编辑者、评论者、只读成员（具体名称以界面显示为准）。
- **自定义角色**：管理员可以自己建，用来 bundles 组织级管理动作。

**步骤（新建自定义角色）**：
1. 点角色列表右上角的加号。
2. 填写角色名与说明。
3. 勾选这个角色包含的组织管理动作（管理部门、管理成员、管理角色、分享授权、导航编排）。
4. 保存。

**步骤（授予角色）**：
1. 在角色列表里选中一个角色。
2. 在角色详情下方的「授予对象」区点「添加成员 / 部门」。
3. 在弹出的选择器里按「选成员」或「选部门节点」两种方式添加。
4. 已授予的对象可以单独移除。

**说明**：**给某个部门授予角色，对该部门的子树全体成员生效**。这一条会让权限范围扩大，添加前务必确认部门范围。

**注意**：自定义角色**不能删除如果有成员还挂着这个角色**，会提示你先迁移，把人都摘干净后再删。

---

### 通讯录的边界与已知限制

- 自定义角色只包含**组织级管理动作**，不包含「某张表 / 某篇文档能不能看」这种资源权限。资源权限由各库设置页和权限管理页负责。
- 组织角色与库内角色是叠加关系，两者独立，不会自动同步。
- 删除部门、删除自定义角色都**没有撤销**。

## 权限（资源授权）

这里的「权限」指**资源级授权**：谁可以看 / 改哪个库、哪张表、哪篇文档，以及是否继承上级。

### 权限从哪里来

| 来源 | 在哪配置 | 影响范围 |
| --- | --- | --- |
| 系统角色 | 不可改 | 整个工作区的基线能力 |
| 组织自定义角色 | 通讯录 → 角色 | 组织管理动作（见上一章） |
| 库内成员角色 | 各库设置页 → 成员 | 该库整体 |
| 文档独立权限 | 内容列表 → 独立权限 | 单篇文档 / 单张画布 |
| 资源树策略 | 工作区设置 → 权限管理 | 任意节点，可精细到字段 |

---

### 权限管理页

**入口**：工作区设置 → 权限管理。

**步骤**：
1. 打开「权限管理」分区。
2. 左侧是资源树（库 → 表 / 文档），点击某个节点。
3. 右侧显示这个节点的当前授权：成员、部门、角色以及各自的权限档位。
4. 修改后保存。

**说明**：这张资源树同时也是左侧导航的「数据源」：没有权限的节点在左侧导航里**直接不出现**，而不是显示出来让你点了再报错。看不到某个库，通常就是这里没给授权。

---

### 中断继承

**说明**：默认下级节点继承上级的授权。如果某个节点需要一套完全不同的权限，可以「中断继承」，让它从此不再跟上级走。

**步骤**：
1. 在权限管理页选中目标节点。
2. 找到「继承」开关，关闭它。
3. 系统会先弹一个**影响确认**窗口，明确告诉我们中断后哪些原先继承来的权限会失效。
4. 确认后才会提交（程序实现上会带一个「已确认」标记，避免误点直接断掉）。

**注意**：中断继承只针对文档、画布一类叶子节点比较常见；中断后，**上级新增的授权再也不会自动给到它**，需要手工维护。

---

### 字段屏蔽

**说明**：可以给某个角色或部门设置「看不到某些字段」，这就是字段屏蔽。被屏蔽的字段对该主体来说像是根本不存在。

**入口**：权限管理页 → 选中节点 → 字段屏蔽配置区（按主体排）。

**注意**：字段屏蔽与被屏蔽字段相关的导出、计算字段是否受影响，以实际表现为准。【待核】

---

### 当前版本的「只读」口径（重要）

**说明**：产品新增了统一的权限引擎，但它的**总开关目前没有打开**。表现是：
- 权限管理分区、文档「独立权限」里的保存按钮、中断继承开关，在默认安装下都是**只读**的，保存不了；
- 判断依据是后端 `/api/v1/meta` 接口里有一个 `authzManage` 开关位，只有明确为 `true` 才允许写。当前版本后端**不下发这个字段**（全服务端代码里检索不到任何一处设置它），所以这个开关从未真正打开；
- 前端代码严格按照「没有明确允许就按禁止处理」（源码 `apps/web/src/features/authz/lib/capability.ts:13`，注释里写得很清楚）。

**影响**：想用精细的资源树授权，必须先让管理员在服务端打开总开关（下发 `authzManage: true`）并重启服务，界面才允许保存。文档如果没有铺到这一步，请不要向用户承诺「在权限管理里点保存即可生效」。

**注意**：这一点与「界面没做入口」性质不同——入口和界面都在，只是被总开关挡成了只读。

---

### 权限的边界与已知限制

- 权限粒度最细到**单篇文档 / 单张画布**（或单个字段的屏蔽），没有更细的块级权限。
- 导航里的剪枝是「无权限即隐藏」，所以找不到入口时先怀疑权限而不是功能坏了。
- 权限变更后，**其他人的界面需要刷新才会生效**，不会实时推送。

## 语义检索

语义检索让搜索不止按关键词，还能按「意思」找到相关内容。默认关闭，只在本机做关键词匹配，**不发送任何内容到外部**。

**入口**：工作区设置 → 语义检索。

![语义检索设置页：模式选择、云端服务配置、总开关、API Key 与重建索引](assets/semantic-search-settings.png)

---

### 选模式

**步骤**：
1. 打开「语义检索」分区。
2. 选择「仅本机关键词检索」或「云端语义检索」。
3. 选「云端语义检索」时会先弹一个**数据出域二次确认**，明确告诉我们检索文本会被发送到外部服务，需要你确认后才生效。

**说明**：
- **仅本机关键词检索**（默认）：只在本工作区数据库里匹配关键词，零外网。
- **云端语义检索**：在关键词之外按语义理解匹配，需要配外部服务，检索文本会发到该服务。

---

### 配置云端服务

**步骤**：
1. 模式选「云端语义检索」后，下方出现服务配置表单。
2. 填写服务地址（baseURL）、模型名、每批数量、超时时间、并发数与重试次数。
3. 点「测试连接」，成功后会提示连接正常并带回向量维度。
4. 点保存。

**说明**：向量维度一般会随服务自动带回，只有自建与兼容服务才需要手工填。

---

### 设置 API Key

**步骤**：
1. 在「密钥」区输入密钥。
2. 点保存（或「轮换」）。
3. 需要换一把密钥时点「轮换」；需要清除时点「清除」并确认。

**说明**：出于安全考虑，密钥**只写不读**——界面上永远只显示「已配置 / 未配置」和掩码后的后四位，不会把明文显示给你。

---

### 总开关（及时覆盖）

**说明**：这里还有一个「检索总门」开关（跟随环境变量 / 启用 / 停用），优先级高于环境变量。改完后：
- 检索接口**即时生效**；
- 索引生成进程**需要重启服务**才按新设置走（界面上会如实标注这一点）。

---

### 重建索引

**步骤**：
1. 在语义检索页底部找到「重建索引」区。
2. 点击后再确认一次。
3. 在弹出的窗口里选择重建范围（可选：全部内容、仅数据库、仅知识库、仅某类内容）。
4. 提交后系统转入后台处理，可以在「覆盖度」面板里跟进进度。

**说明**：如果已经有重建任务在跑，再提交会被拒并给出中性提示，不会覆盖前一个任务。

### 看覆盖度与索引规模

## MCP 接入

MCP 接入让外部 AI 客户端（桌面 AI 助手、脚本等）以你的身份读写工作区内容，靠一枚令牌授权。

**入口**：工作区设置 → MCP 接入。

![MCP 接入信息块：端点、认证头与示例命令](assets/mcp-connect-block.png)

**说明**：这个分区只在**企业组织版且已开启**时才出现。看不到它说明当前部署没开这个能力。

---

### 第一步：看接入方式

打开分区后最上面的「接入方式」块里有三样东西：
- **MCP 端点**：按你当前访问的站点动态生成（例如 `https://你的域名/mcp`），**不要照抄别人的示例地址**。
- **认证头**：`Authorization: Bearer <令牌>`。
- **示例命令**：可以直接复制，把令牌换成你自己的。

---

### 第二步：签发令牌

**步骤**：
1. 在签发表单里填令牌名称（例如「数据同步脚本」）。
2. 选择有效期：30 天 / 90 天 / 365 天 / 永不过期（默认 90 天）。
3. 点签发。
4. 选「永不过期」时会额外弹出强警示二次确认，告知长期风险后再让你确认。
5. 签发成功后，**明文令牌只在这一次弹窗里显示**，关掉就看不到了，请立即复制保存。

**说明**：列表里后续只能看到令牌的**前 14 位前缀**，用来分辨是哪一枚，不会也不会以明文形式再显示完整内容。令牌明文不会写入浏览器本地存储或地址栏。

---

### 第三步：填到 AI 客户端

**步骤**：
1. 复制刚显示的明文令牌。
2. 在支持 MCP 的客户端里新建服务，填上面说的端点地址。
3. 认证方式选「HTTP 头」，头名称填 `Authorization`，值填 `Bearer 加一枚空格再加令牌`。
4. 保存后客户端会拉工具列表，能拉到就说明通了。

---

### 第四步：吊销

**步骤**：
1. 在「已签发的令牌」列表里找到那一行。
2. 点右侧「吊销」。
3. 在确认弹窗里阅读影响后再点「确认吊销」。
4. 吊销立即生效，那枚令牌的调用一律被拒。

**说明**：列表同时显示每枚令牌的状态（生效中 / 已过期 / 已吊销）、创建时间、最后使用时间、有效期。「从未使用」说明还没被调用过。

---

### 令牌能做什么：跟随签发人

**说明**：重要的一点——**令牌的权限不单独配置，它等于签发者你这个账号当下能做什么**。
- 你今天能看哪些库，令牌就能看哪些库；
- 你的权限明天被收窄，令牌立刻跟着收窄；
- 你账号被停用，令牌立即失效。

**注意**：界面上手写列了一列「权限」项，显示的是「跟随签发者」的意思，**不是**可以勾选的权限清单。别指望在那里勾选 scope。

## 常见问题与自助排查

### 忘记密码怎么办

- **界面上没有自助找回**。按「忘记密码」是找不回链接的。
- 请联系本工作区的管理员，由管理员在后台重置；如果是自建部署，管理员可以用初始化工具重置。
- 会话过期被踢到登录页是两回事：重新登录即可，原凭证没丢。

---

### 数据误删怎么找回

| 删了什么 | 去哪找 |
| --- | --- |
| 文档 / 画布 | 该知识库的回收站（第二列底部「回收站」，或工作区设置 → 回收站），30 天内可找回 |
| 数据表 / 字段 / 记录 | 该数据库的回收站（第二列底部「回收站」），30 天内可找回 |
|画布里的某个图形 | 立刻点 Command / Ctrl + Z 撤销；已经保存出去的用「版本历史」回滚 |
| 文档里删掉的一大段字 | 立刻点 Command / Ctrl + Z；已经保存出去的用「版本历史」回滚到删之前的版本 |
| 数据库（整个库） | **找不回来**，库不进回收站 |

**注意**：回收站里的「彻底删除」和「清空回收站」都不可恢复，弹窗会明说。看到那种提示词请停一下手。

---

### 权限不足的表现

**现象自查表**：

| 现象 | 通常原因 |
| --- | --- |
| 看不到某个库 / 某个文档 | 没有查看权限，导航直接被剪掉了，不是功能坏了 |
| 顶栏标题输入框是灰的、没有「保存」按钮 | 这篇内容你是只读权限 |
| 「新建文档 / 新建画布」按钮没有出现 | 你的库内角色是「可评论」或「仅查看」 |
| 工作区设置里缺某个分区 | 角色不允许（所有者 / 管理员 / 普通成员可见范围不同） |
| 找不到「MCP 接入」分区 | 当前部署没开企业组织能力 |
| 「独立权限」弹窗里的选项是灰的 | 权限引擎总开关没开，见「权限」一章的「只读口径」 |

**注意**：本产品的权限策略是「没有就是不存在」——无米代表性的按钮是直接不渲染，而不是置灰后点了报错。所以「找不到」和「没权限」往往是同一件事。

---

### 页面空白或一直转圈

1. **先看是不是只有某一个页面白**：换到别的页面，如果都白，先刷新。
2. **看提示文字**：加载失败一般会就地给一张错误卡片并带「重试」按钮，先点重试。
3. **看是不是权限问题**：无权访问的资源会显示明确的错误态 / 无权限态，而不是白屏。
4. **画布一直显示「画布加载中…」**：画布组件是按需加载的，网络慢时会停在这里较长时间，等一下或刷新重试。
5. **文档打开后内容空、顶部提示有本地草稿**：点提示条上的「恢复草稿」。
6. 以上都不行，清一下浏览器缓存再进；还不行请把浏览器控制台里的报错截图给管理员。

---

### 分享链接打不开

1. 先确认链接完整没有被截断（尤其是聊天工具自动截断長 URL）。
2. 页面显示「分享链接已失效或被取消」，说明分享人已经关掉了外部链接开关，请让对方重新开一下。
3. 从子路径部署的实例访问时，链接**必须带网关前缀**，手打链接容易漏。
4. 如果你能看到内容但不能改，是对方设成了「仅可见」，需要编辑请让对方改成「可编辑」。

---

### 令牌调用报 401

1. 先确认令牌没有被吊销（列表状态列看得出）。
2. 看是不是过期了。
3. 确认认证头格式正确：`Authorization: Bearer <空格><令牌>`，空格只能是**一枚**。
4. 以上都对还报 401，多半是签发者账号被停用或权限变更了——令牌权限是跟着账号实时算的。

---
