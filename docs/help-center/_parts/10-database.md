## 界面结构速览

开始之前先认清三个区域，后面的所有入口描述都基于它们：

- 第一列（L1）：最左侧竖条，列出你有权限的全部数据库与知识库。点一个库即进入它。
- 第二列（L2）：选中某个库后展开的面板，顶部是库名，下面是这张库里的全部数据表，最底部是回收站入口。
- 内容区：右侧大区域。选中某张表后，这里显示该表的当前视图（网格 / 看板 / 画廊 / 日历 / 详情 / 表单）。

![左侧第一列库列表与第二列表列表](assets/nav-l1-libraries.png)

**说明**：本系统没有「切换工作区」的功能。你的全部数据库都在第一列里，直接用第一列或顶栏切换即可。

## 工作区与库

### 在库之间切换

**入口**：两种方式，任选其一
- 第一列直接点击目标库名。
- 顶栏中部的当前库名 → 点击展开下拉 → 输入关键字搜索 → 点击目标库。

![顶栏库切换下拉](assets/library-switcher.png)

**步骤**：
1. 点击顶栏中部的当前库名，展开列表。
2. 库很多时，在搜索框输入库名关键字过滤。
3. 点击目标库名完成切换。
4. 需要新建库时，点下拉底部的「新建库」。

**说明**：下拉底部另有「新建库」入口，与第一列的「新建数据库」按钮等价。

### 新建数据库

**入口**：第一列顶部「新建数据库」按钮（组件 `NavLibraryBlock`）；或顶栏库下拉底部「新建库」。

![新建数据库弹窗](assets/create-library-modal.png)

**步骤**：
1. 点击第一列顶部的「新建数据库」。
2. 在弹窗中填写库名称。
3. 点击创建。
4. 创建成功后自动进入新库。

**说明**：库的图标颜色由系统按库名自动生成，不需要你选；想要改颜色或图标见下一节。

### 修改库的图标与颜色

**入口**：进入库 → 顶栏或库设置页 → 库设置 → 「概览」页 → 点击库名前的图标。

![库设置概览页](assets/base-settings-overview.png)

**步骤**：
1. 打开目标库，进入库设置页（路由 `/base/:baseId/settings`）。
2. 停留在「概览」页。
3. 点击库名左侧的图标，弹出图标与颜色选择器。
4. 选择图标和颜色，选择后立即生效，无需保存。

**说明**：需要库的「管理」权限（`canManageBase`）。没有该权限时，整片设置区域不会显示，图标也不可点。

### 重命名库

**入口**：库设置页 → 「概览」页的库名称输入框。

**步骤**：
1. 进入库设置页（`/base/:baseId/settings`）。
2. 在「概览」页修改名称输入框内的文字。
3. 点击保存。

**说明**：需要库管理权限（`canManageBase`）。没有该权限时名称是只读文本，无法编辑。

### 删除数据库

**入口**：库设置页 → 「危险操作」页 → 「删除整个 Base」。

![库设置危险操作区](assets/base-settings-danger.png)

**步骤**：
1. 进入库设置页，切到「危险操作」页。
2. 点击红色的「删除整个 Base」按钮。
3. 在确认弹窗中**完整输入库名**（不是勾选，是手打名字）。
4. 点击「删除数据库」完成删除，页面会跳回首页。

**说明**：需要库管理权限（`canManageBase`）。**删除库不可恢复**——库虽然从列表里消失，但它不会进入回收站，回收站只收纳数据表、字段、记录三类内容，没有「库」这一类。

**注意**：删除前请先用「导出」把需要的表导成 CSV 备份。这是全系统唯一不可恢复的破坏性操作之一。

### 库级分享链接

**入口**：库设置页 → 「分享」页。

![库分享链接面板](assets/base-settings-share.png)

**步骤**：
1. 进入库设置页，切到「分享」页。
2. 点击创建链接，按需设置有效期。
3. 点击复制按钮，把链接发给协作者。
4. 不再需要时点击删除（会要求二次确认，该操作不可撤销）。

**说明**：需要库管理权限（`canManageBase`）。分享链接是**库级别**的，拿到链接的人看到的是整个库，不是单张表。目前没有「单条记录分享」功能。

### 成员与权限

**入口**：库设置页 → 「成员与权限」页。

![成员与权限面板](assets/base-settings-members.png)

**步骤**：
1. 进入库设置页，切到「成员与权限」页。
2. 在成员列表里为每个成员选择角色。
3. 需要新增成员时使用邀请入口。

**说明**：页面下方有一张权限矩阵表，说明每种角色能做什么，该表只用于查看，不能在页面上修改。权限共五类：管理库、管理表结构、编辑数据、评论、查看。

**注意**：如果你看不到某个按钮（比如表的三点菜单、新建字段按钮），通常不是按钮坏了，而是你当前角色没有对应权限——系统在无权限时直接不显示这些入口。

### 查看库的关系图（ERD）

**入口**：库设置页 → 「概览」页的关系图入口（路由 `/base/:baseId/erd`）。

**步骤**：
1. 进入库设置页「概览」页。
2. 点击关系图入口。
3. 在关系图页查看各张表之间的关联结构。

**说明**：只读查看，不能在图上改结构。

## 数据表

数据库里的全部表操作都集中在第二列的表行上。

### 新建数据表

**入口**：第二列顶部的「+ 新建数据表」（表行列表上方）。

![第二列新建数据表](assets/l2-new-table.png)

**步骤**：
1. 在第一列选中目标库，展开第二列。
2. 点击列表上方的「新建数据表」。
3. 在出现的输入框里输入表名。
4. 按回车（或点右侧对勾）创建；按 Esc 取消。
5. 创建成功后自动跳进新表。

**说明**：新表会自带一组默认字段。需要「管理表结构」权限（`canManageSchema`），否则这个按钮根本不会出现。

**表名不能重名**：同一个库里，表名必须唯一。输入时如果和库里已有的表同名，输入框下方会立刻出现红字提示「表名「X」已存在，请换一个」，同时右侧对勾变灰点不了；换个名字红字就消失。表名首尾的空格会被自动去掉（「 客户表 」和「客户表」算同一个名字），只打空格则不能创建。不同库之间可以有同名表，互不影响。

### 重命名数据表

**入口**：第二列 → 鼠标悬停在目标表行 → 行尾出现的三点菜单 → 「重命名」。

![表行三点菜单](assets/table-row-menu.png)

**步骤**：
1. 在第二列找到要改名的表，把鼠标移到这一行上。
2. 点击行尾出现的三点图标。
3. 点击「重命名」。
4. 在弹窗里改成新名字，点保存（或按回车）。

![重命名数据表弹窗](assets/table-rename-modal.png)

**说明**：需要「管理表结构」权限（`canManageSchema`）。没有该权限时三点菜单不会出现。

**注意**：表名也是导出 CSV 时的默认文件名依据，建议起有辨识度的名字。

**改不成同名**：如果你输入的名字和库里另一张表重了，弹窗里会立刻出现红字「表名「X」已存在，请换一个」，保存按钮同时变灰。改成自己现在的名字（或只加空格）不受影响——那不算重名。

### 复制数据表

**入口**：第二列表行 → 三点菜单 → 「复制表（含数据）」或「复制表（不含数据）」。

**步骤**：
1. 悬停目标表行，点三点菜单。
2. 选择「复制表（含数据）」保留全部记录，或选「复制表（不含数据）」只复制表结构。
3. 等待提示「已复制数据表」，新表出现在第二列列表里。

**说明**：两个选项的区别只有记不记录数据，字段结构、视图配置都会一起复制。需要 `canManageSchema` 权限。

**注意**：复制出的新表不会自动跳过去，需要在第二列列表里找到它点开。

**副本的命名**：默认叫「原表名 副本」。因为表名在同一个库里必须唯一，如果这个名字已经被占了，会自动往后排号——「原表名 副本 2」「原表名 副本 3」，不会覆盖已有的表，也不会报错中断。

### 清空表数据

**入口**：第二列表行 → 三点菜单 → 「清空数据」。

**步骤**：
1. 悬停目标表行，点三点菜单。
2. 点击「清空数据」。
3. 在弹窗中**完整输入表名**确认。
4. 点击确认按钮，等待提示「已清空数据，记录已移入回收站」。

**说明**：需要 `canManageSchema` 权限。**清空后记录进入回收站，可以到回收站里恢复**，表结构和字段都保留。

**注意**：网格视图工具栏「更多 → 清空表」是同一个功能，但那里的提示文字写的是「不可恢复」，属于已知文案错误，请以本节口径为准：清空是可恢复的。

### 删除数据表

**入口**：第二列表行 → 三点菜单 → 「删除表」。

**步骤**：
1. 悬停目标表行，点三点菜单。
2. 点击「删除表」。
3. 阅读确认弹窗后点击「删除数据表」。
4. 删除后如果误删，立刻点击右下角提示条上的「撤销」按钮（约 6 秒内有效）。
5. 错过撤销窗口时，去回收站里恢复。

**说明**：需要 `canManageSchema` 权限。删除是软删除，30 天内可从回收站恢复。

**注意**：如果当时正停在这张表上，页面会自动跳回该库的第一张表，这是正常的。

### 修改表的图标与颜色

**入口**：打开某张表 → 网格视图左上角、表名左侧的图标。

![网格视图左上角表图标](assets/table-icon-picker.png)

**步骤**：
1. 打开目标表，确保当前是网格视图。
2. 点击左上角表名左侧的图标。
3. 在弹出的选择器里选图标与颜色，即时生效。

**说明**：只有网格视图提供这个入口；看板、画廊、日历、详情页顶部不带图标编辑入口。

## 字段

### 新建字段

**入口**：三种方式，效果相同
- 网格工具栏「字段」面板 → 顶部蓝色「新建字段」。
- 表头任意列的下拉菜单（见「编辑字段」）。
- 网格视图最后一列的「+」列头。

![字段编辑器与类型选择](assets/field-editor-sheet.png)

**步骤**：
1. 打开目标表，切到网格视图。
2. 点击工具栏的「字段」按钮，打开字段面板。
3. 点击面板顶部的「新建字段」。
4. 在编辑器里填写字段名。
5. 选择字段类型（分基础 / 选择 / 高级 / 布局 / 计算 / 系统六组）。
6. 按类型填写附加配置（例如单选的选项、关联的目標表）。
7. 点击保存。

**说明**：需要 `canManageSchema` 权限。**字段类型一旦创建就不能再改**——如果类型选错了，只能删掉重建（数据会一起丢失）。系统字段（创建时间、最后修改时间、创建人、最后修改人）由系统维护，不能手工新建编辑。

**注意**：布局类的「选项卡分组」「子表格」只在详情页呈现，不会作为网格的一列出现。

### 编辑与重命名字段

**入口**：
- 表头下拉菜单 → 「重命名 / 编辑字段」。
- 工具栏「字段」面板 → 悬停字段名 → 右侧齿轮图标。

![表头列下拉菜单](assets/grid-header-cell-menu.png)

**步骤**：
1. 点击目标列的表头，展开列菜单。
2. 点击「重命名 / 编辑字段」。
3. 在编辑器里修改名称或配置。
4. 点击保存。

**说明**：需要 `canManageSchema` 权限。类型不可改。系统字段打开后是只读的。

### 删除字段

**入口**：表头下拉菜单 → 「删除字段」。

**步骤**：
1. 点击目标列的表头，展开列菜单。
2. 点击红色的「删除字段」。
3. 按提示确认。

**说明**：需要 `canManageSchema` 权限。字段删除后可在回收站恢复。

**注意**：删字段会一并删掉这一列在所有记录里的数据。如果这个字段被公式、查阅、聚合字段引用，那些字段会跟着失效，请先在详情页检查引用关系。

### 控制字段在某视图里是否显示

**入口**：网格工具栏「字段」按钮 → 「显示字段」列表。

![字段显隐面板](assets/toolbar-fields-panel.png)

**步骤**：
1. 点击工具栏「字段」，打开面板。
2. 在「显示字段」列表里勾选或取消勾选字段名。
3. 改动即时生效。

**说明**：这是**视图级**设置——只影响当前视图，不影响其它视图，也不影响表里真实存在的字段。隐藏字段不等于删除字段，数据还在。

### 字段类型一览

下表列出全部 30 种字段类型。标「不可手输」的类型由系统计算或维护，在网格里双击不会进入编辑。

| 类型 | 用途与填写方式 |
| --- | --- |
| 单行文本 | 短文本，如姓名、标题。是表里最常见的主字段 |
| 多行文本 | 较长文本，单元格内可换行 |
| 富文本 | 带格式的文本，在详情 / 表单里编辑 |
| 数字 | 数值，可参与统计与公式 |
| 货币 | 带货币符号的数值，可设币种与小数位 |
| 百分比 | 以百分比形式显示与输入的数值 |
| 时长 | 以时间长度显示的数值 |
| 日期 | 只到日期，可用日历选择器，可设是否含时间 |
| 日期时间 | 精确到时间的日期 |
| 复选框 | 勾选 / 取消。单击即可切换，不需要双击 |
| 单选 | 从预设选项里选一个。选项可配名称与颜色 |
| 多选 | 从预设选项里选多个，每个值以标签呈现 |
| 邮箱 | 邮箱地址，输入时校验格式 |
| 链接 | 网址，可点击跳转 |
| 电话 | 电话号码 |
| 评分 | 星级评分，可设满分星数 |
| 自动编号 | 系统按序自动生成的编号，**不可手输**，也不能修改 |
| JSON | 结构化数据，填写合法 JSON 文本 |
| 附件 | 上传文件，见「附件上传与下载」 |
| 关联 | 关联到另一张表的记录，见「关联字段」 |
| 查阅 | 沿关联把另一张表的字段值带过来，**不可手输** |
| 聚合 | 对关联记录做求和、平均、计数等汇总，**不可手输** |
| 计数 | 统计关联记录条数，**不可手输** |
| 公式 | 用表达式由其它字段算出结果，**不可手输** |
| 选项卡分组 | 详情页的分组容器，自身无值，不出现在网格列里 |
| 子表格 | 在详情页以子表形式展示关联记录，不出现在网格列里 |
| 创建时间 | 系统自动记录，不可手输也不可配置 |
| 最后修改时间 | 系统自动记录，不可手输也不可配置 |
| 创建人 | 系统自动记录，不可手输也不可配置 |
| 最后修改人 | 系统自动记录，不可手输也不可配置 |

### 关联字段（关联另一张表）

**入口**：新建或编辑字段 → 类型选「关联」（在「高级」组里）。

**步骤**：
1. 按「新建字段」的步骤打开编辑器，类型选「关联」。
2. 选择要关联的目标表。
3. 选择关联方式：多对多 / 一对多 / 多对一。
4. 保存。
5. 之后在网格或详情页的关联单元格里，从目标表的记录中挑选。

**说明**：关联建立后，目标表会出现一个「反向」字段，反向字段由系统维护，不能单独删除或修改名称。

**注意**：关联单元格里可挑选的记录列表，由服务端按关键字搜索返回，记录很多时请输入关键字筛选，不要指望一次加载全部。

### 公式 / 查阅 / 聚合 / 计数 字段

**入口**：新建或编辑字段 → 类型选「计算」组里的对应类型。

**步骤**：
1. 打开字段编辑器，类型选「公式」（或查阅 / 聚合 / 计数）。
2. 按类型配置来源：公式填表达式并引用其它字段；查阅选关联字段 + 要带过来的目标字段；聚合选关联字段 + 汇总方式；计数选关联字段。
3. 保存。

**说明**：这四类都是计算字段，值由系统算出，**不能手工输入**，在网格里双击也不会进入编辑。

**注意**：大表上如果用到计算字段，底部统计条可能显示为灰色并提示降级，这是容量保护，不是出错。

## 视图

一张表可以有多个视图，视图决定「同一份数据怎么呈现」。筛选、排序、分组、行高、字段显隐、行颜色都是**视图级**设置，改了只影响当前视图。

### 切换视图

**入口**：网格工具栏最左侧的当前视图名 → 点击展开下拉。

![视图切换下拉](assets/view-switcher.png)

**步骤**：
1. 点击工具栏最左侧的视图名。
2. 在下拉里点击目标视图（当前视图前有对勾）。
3. 页面切换到该视图。

**说明**：下拉里列的是当前表的全部视图。

### 新建视图

**入口**：网格工具栏视图名下拉 → 底部「新建视图」。

![新建视图弹窗](assets/view-new-modal.png)

**步骤**：
1. 点击工具栏视图名，展开下拉。
2. 点击「新建视图」。
3. 在弹窗里点选视图类型：网格、画廊、表单、详情、看板、日历。
4. 填写视图名称（默认是类型名 + 「视图」）。
5. 点击「创建」。

**说明**：需要 `canManageSchema` 权限。

### 重命名视图

**入口**：视图名下拉 → 「重命名当前视图」。

**步骤**：
1. 展开视图名下拉。
2. 点击「重命名当前视图」。
3. 输入新名字，点保存。

**说明**：需要 `canManageSchema` 权限。

### 删除视图

**入口**：视图名下拉 → 「删除当前视图」。

**步骤**：

## 记录

### 新建记录

**入口**：四种常用方式
- 网格工具栏左侧蓝色「新建记录」按钮。
- 网格最后一行的空白行「+」。
- 看板视图某列底部的「+」。
- 记录抽屉底部的「新建」按钮。

**步骤（网格方式）**：
1. 打开目标表的网格视图。
2. 点击工具栏「新建记录」。
3. 新行出现在网格底部，直接在单元格里填写。
4. 填写完点其它位置即自动保存。

**说明**：需要「编辑数据」权限（`canEditData`）。没有该权限时「新建记录」按钮是置灰的，鼠标悬停会提示「无编辑权限」。

### 在网格里直接编辑单元格

**入口**：网格视图的任意可编辑单元格。

**步骤**：
1. 双击目标单元格进入编辑。
2. 修改内容。
3. 按回车或点击其它位置提交。
4. 按 Esc 放弃本次修改。

**说明**：复选框字段单击即可切换，不必双击。自动编号、公式、查阅、聚合、计数、创建时间、最后修改时间、创建人、最后修改人这类字段不可手输，双击不会进入编辑。

**注意**：使用中文输入法时，输入法组字过程中的回车不会被当成提交，组字结束后再按回车才生效——这是刻意的防误提交设计。

### 删除记录与撤销

**入口**：选中行后的批量删除按钮；或记录抽屉里的删除。

**步骤**：

5. 错过撤销窗口时，去回收站恢复。

**说明**：删除是软删除，进回收站，30 天内可恢复。需要 `canEditData` 权限。

**注意**：撤销只在提示条存在的那几秒内有效，刷新页面或离开当前视图都会让撤销机会消失。

### 批量修改记录

**入口**：选中多行后工具栏的批量编辑按钮。

**步骤**：
1. 勾选要修改的多行。
2. 点击工具栏的批量编辑按钮。
3. 在弹窗里选择要改的字段并填写新值。

5. 点击关闭按钮或抽屉外区域退出。

### 在记录里评论

**入口**：记录抽屉底部的评论区。

**步骤**：

## 表单设计器

表单设计器是一个所见即所得的排版工具，用来编排「详情视图」里一条记录的版面。它排的是详情页长什么样，不是给别人填数据的收集表单。

### 进入表单设计器

**入口**：三种方式
- 第二列表行 → 三点菜单 → 「编辑表单」。
- 详情视图右上角的齿轮菜单 → 「编辑表单」。
- 记录抽屉里点击排版编辑按钮。

![表单设计器画布](assets/form-designer-canvas.png)

**步骤**：
1. 在第二列悬停目标表行，点三点菜单。
2. 点击「编辑表单」（菜单里标注为「进入表单设计器」）。
3. 页面跳转到该表并打开设计器（地址栏带 `?design=1`）。
4. 编辑完成后点击保存。

**说明**：需要 `canManageSchema` 权限。设计器当前只提供「表单设计」——左侧字段库、中间画布、右侧字段设置面板，用来编排详情视图一条记录的版面。另外，设计器顶部工具栏的「历史」按钮提供**布局的版本管理与回退**，可以留档、预览历史版面并把旧版填回编辑器，详见下一节。

### 在设计器里排版

**入口**：设计器左侧字段面板 + 中间画布 + 右侧字段设置面板。

![字段设置面板](assets/form-designer-field-settings.png)

**步骤**：
1. 从左侧字段面板把字段拖到中间画布，或点击添加。
2. 在画布上拖动字段调整顺序与所在行。
3. 点击画布上的某个字段，在右侧设置面板里调整它的宽度占比等属性。
4. 需要分组时添加「选项卡分组」字段，把字段放进不同选项卡。
5. 点击保存退出。

**说明**：字段宽度按 25% / 50% / 75% / 100% 四档排布，一行可以放多个字段。保存后，详情视图与记录抽屉都会按这个版面呈现。

### 恢复默认版面

**入口**：详情视图右上角齿轮菜单 → 「重置为默认布局」。

**步骤**：
1. 切到详情视图。
2. 点击右上角齿轮图标。
3. 点击「重置为默认布局」。

**说明**：重置后版面回到按字段顺序自动排列的状态，不会删除任何字段或数据。

### 表单布局的版本管理与回退

**入口**：设计器顶部工具栏的「历史」按钮 → 右侧滑出抽屉，标题「布局版本历史」。

**说明**（抽屉顶部原文）：保存布局时自动留档，10 分钟内不重复存。

**版本列表**：左侧列表按版本号倒序排列，每条显示 `v{版本号}`；手动存的版本会带上备注，显示成 `v{版本号} · {备注}`；下面一行是相对时间与绝对时间。列表**不显示操作人**。

**空态**：一个版本都没有时，列表里显示——还没有版本。点「保存布局」会自动留第一版；带备注的手动版本不会被自动清理。

#### 预览某个版本

**步骤**：
1. 点设计器顶部工具栏的「历史」，打开版本历史抽屉。
2. 在左侧列表里点一个版本。
3. 右侧显示该版本的版面预览，包含选项卡的结构。

**说明**：预览是只读的，**不会改动你当前的数据**。要退出预览，点别的版本或关掉抽屉即可。

#### 把当前草稿存为新版本

**步骤**：
1. 在抽屉左上方的备注输入框里填备注。
2. 点输入框右侧的保存按钮（也可以按 Enter）。
3. 存完后左侧列表里立刻多一条带备注的版本。

**说明**：备注有长度上限，留空时存不了。带备注的版本属于**手动版本**，不会被自动清理——打算大改之前，先手动存一版是最稳的做法。

#### 回退到某个版本

**步骤**：
1. 在列表里选中要回退的版本，点预览区右上角的「回退到此版本」。
2. 在弹出的二次确认框里确认。框里会说明：当前编辑器里未保存的改动会被替换掉。
3. 确认后，系统会**先把你当前的草稿自动存成一个版本**（备注「回退前自动备份」），再把选中的历史版本填回编辑器草稿区。
4. 在编辑器里核对版面，确认没问题后**再点「保存布局」**才真正生效。

**注意**：回退这一步最容易误解，请记住——
- 回退**只把选中的历史版本填回编辑器的草稿区**，**不会立刻改线上的版面**。
- 要真正生效，**必须再点一次「保存布局」**；取消或不保存就退出的话，线上版面不会有任何变化。
- 第 3 步那份自动备份是防误操作的安全网：即便回退错了，原来那份草稿也还在版本历史里，找回来即可。
- 回退会一并还原该表单所属数据表上的选项卡配置。选项卡配置是**表级**的，不是视图级的，所以同一张表的其它视图也会跟着变。

**自动留档的清理规则**：
- 自动存的版本有数量上限，超过后最旧的会被删掉。
- 手动存的（带备注的）版本不会被自动清理。
- 删除视图时，会连带清掉它的全部版本。

## 导入与导出

导入与导出的入口都在**网格视图工具栏的右侧**，搜索框旁边，是常驻按钮。

### 导入 CSV

**入口**：网格工具栏「导入」按钮（上传图标）。

![导入字段映射](assets/import-wizard-mapping.png)

**步骤**：
1. 打开目标表，切到网格视图。
2. 点击工具栏「导入」。
3. 第 1 步：选择本地 CSV 文件，或直接粘贴 CSV 文本内容。
4. 第 2 步：核对字段映射——每一列落到哪个字段。留空表示按列名自动匹配；同名则写入，没有同名且你有建字段权限时会自动新建字段。
5. 第 3 步：核对影响范围，可返回上一步修改。
6. 第 4 步：执行并查看结果（成功 / 失败行数），有失败行时可下载错误明细。

![导入结果](assets/import-wizard-result.png)

**说明**：只支持 CSV 格式。导入是一次性整批处理，中途不逐行汇报进度；弹窗可以关掉，导入会在后台继续。

**注意**：映射面板不提供「忽略这一列」的选项，因为后端不支持该语义——不想导入的列，请先在 CSV 文件里删掉。没有建字段权限时，CSV 里表内不存在的列会被跳过而不导入。

### 导出 CSV

**入口**：网格工具栏「导出」按钮（下载图标）。

![导出对话框](assets/export-dialog.png)

**步骤**：
1. 打开目标表，切到网格视图。
2. 点击工具栏「导出」。
3. 选择导出范围：「当前视图」按当前筛选与排序导出，或「全部数据」忽略筛选导出整张表。
4. 确认格式为 CSV。
5. 点击「导出」，浏览器下载文件。

**说明**：当前只支持 CSV，Excel（.xlsx）与「打包下载附件」尚未实现，界面上这两项标注为规划中，点了只会提示尚未提供。

**注意**：CSV 只导出文本内容，附件不会被打包进文件。

1. 在第一列选中目标库，展开第二列。
2. 点击列表最底部的「回收站」。
3. 在回收站页查看被删除的数据表、字段、记录。

**说明**：回收站是**库级别**的，只显示当前库里被删的内容，需要到对应的库里去找。

**注意**：**数据库本身不进回收站**。删掉的库不在这里，也找不回来。

### 恢复内容

**入口**：回收站列表里每一项的「恢复」按钮。

**步骤**：
1. 打开回收站。
2. 找到要恢复的项（可按类型区分：数据表 / 字段 / 记录）。
3. 点击该项的「恢复」。
4. 等待提示「已恢复」，回到对应表里查看。

**说明**：需要「编辑数据」权限（`canEditData`）。恢复记录时，它与其它记录的关联关系也会一并回来。

### 彻底删除

**入口**：回收站列表里每一项的「彻底删除」；或顶部「清空回收站」。

**步骤**：
1. 打开回收站。
2. 点击某一项的「彻底删除」，或点击顶部「清空回收站」一次清空全部。
3. 阅读确认提示后点击确认。

**说明**：彻底删除不可恢复。清空回收站需要库管理权限（`canManageBase`），没有该权限时这个按钮不会出现。单项的彻底删除按不同的确认等级提示，请看清提示中的对象名称再确认。

## 全局搜索

### 用快捷键搜索全站内容

**入口**：任意页面按 Command + K（Windows / Linux 为 Ctrl + K）。

![全局搜索对话框](assets/search-dialog.png)

**步骤**：
1. 在任意页面按下 Command + K。
2. 输入关键字。
3. 用上下方向键在结果里移动，回车打开选中项。
4. 按 Esc 关闭。

**说明**：全局搜索能搜到两类内容——全部数据库里的**记录**，以及知识库里的**文档与画布**。搜索结果跨库，不需要先切到某个库。点开记录结果会直接跳到该记录所在的库与表，并自动打开记录抽屉。

**注意**：这个搜索和网格工具栏右侧那个「搜索此视图」的搜索框不是一回事——搜索框只在当前视图内过滤，全局搜索是跨库查找。

## 暂未提供入口的能力

下面这些功能**当前版本没有界面入口**，请不要在文档里把它们当作可用功能介绍，也不要向用户承诺。它们大多已在代码中预留，将在后续版本提供。

| 能力 | 现状说明 |
| --- | --- |
| 切换工作区 | 无工作区切换器，全部库平铺在第一列 |
| 手工拖动调整字段顺序 | 后端支持字段移动，但界面上没有拖拽入口，字段顺序按创建顺序排列 |
| 指定任意列为冻结列 | 首列自动冻结，不能手工指定，也没有取消冻结的开关 |
| 画廊视图指定封面字段与卡片字段 | 系统按字段顺序自动取，无设置入口 |
| 表单视图挑选 / 排序字段 | 表单字段由系统自动生成，无配置界面 |
| 看板视图重新选择分列字段 | 首次进入时选一次，之后无更改入口（可新建看板视图重选） |
| 日历视图重新选择日期字段 | 首次进入时选一次，之后无更改入口（可新建日历视图重选） |
| 详情视图指定显示 / 隐藏字段 | 通过表单设计器排版间接控制，没有独立的显隐开关 |
| 导出 Excel（.xlsx） | 服务端未提供导出端点，界面标注为规划中 |
| 导出时打包附件 | 未实现，CSV 只含文本 |
| 单条记录级分享 | 只有库级分享链接，无记录级分享 |
| 网格与抽屉内附件直接下载 | 只显示文件名，需到看板 / 画廊视图点链接下载 |
| 主字段（首列）手工指定 | 首列是当前视图最左侧的可见字段，通过调整字段显隐间接改变 |
