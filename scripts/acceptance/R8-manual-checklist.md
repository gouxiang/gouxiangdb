# R8 手工签字清单（RC13~RC25 画布/正文 Web 手测）

门② G2 自动化只到"内容字节 + blocks round-trip"（mdToBlocks→blocksToMd 逐字一致）。
下列画布/正文 **Web 端人工交互**不进 G2 自动化，按 team-lead R8 裁决在此登记签字。
直升演练（v0.1.0→M7）通过后，由验收人在候选构建上逐项手测并签字。

| # | 用例 | 期望 | 结果 | 验收人 | 日期 |
|---|------|------|------|--------|------|
| RC13 | 旧库普通文档在新 Web 编辑器打开 | 正文完整、格式不塌 | | | |
| RC14 | 旧库 20000 字长文档打开/编辑/保存 | 不截断、不卡顿、版本递增 | | | |
| RC15 | 旧库 Drawnix 画布打开 | 元素/几何/连线/备注全在 | | | |
| RC16 | 画布 gxDocRef 内链五形态点击 | 正确跳转/悬停卡 | | | |
| RC17 | 深 3 闭包画布逐级打开 | 前三层可开、第四层拦 | | | |
| RC18 | 画布编辑后提交（commit_elements） | 六不变量成立、可重开 | | | |
| RC19 | 文档块（标题/列表/引用）渲染 | 块类型与样式正确 | | | |
| RC20 | 文档中插入/编辑图片块 | 上传、回显、删除正常 | | | |

| RC24 | 文档并发编辑乐观锁 | 冲突 409 VERSION_CONFLICT 提示 | | | |
| RC25 | 附件字段在记录详情打开/下载 | 字节与磁盘 sha256 一致 | | | |

说明：
- 自动化已覆盖的不在此表（记录字段字节、正文 content 逐字节、画布 JSON 元素 0 diff、blocks round-trip、分享 HTTP 5/5、附件 sha256）。
- 本清单只登记"需人眼/真机交互"项；签字留档不阻塞 G2 自动化门，但门②最终过闸需此表签完。
